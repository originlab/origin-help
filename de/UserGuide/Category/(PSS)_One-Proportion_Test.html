(PSS) Test von Anteilen bei einer Stichprobe

PSS-OneProportionTest


Verwenden Sie diese Funktion zum Bestimmen der Trennschärfe eines Tests von Anteilen bei einer Stichprobe bei gegebenem Stichprobenumfang oder des erforderlichen Stichprobenumfangs, um eine festgelegte Trennschärfe für einen Test von Anteilen bei einer Stichprobe zu erhalten.

Allgemein gesagt können die Werkzeuge für Trennschärfe und Stichprobenumfang auf zwei Arten verwendet werden ­ zur Stichprobenschätzung und zur Berechnung der Trennschärfe. Ersteres kann verwendet werden, um den Umfang einer Stichprobe zu bestimmen, damit eine bestimmte Trennschärfe beim Aufbau eines Versuchs sicher gestellt wird. Letzteres kann verwendet werden, um die Genauigkeit des Ergebnisses zu schätzen, nachdem ein Versuch für eine festgelegte Anzahl von Stichproben durchgeführt wurde.

Zum Bestimmen von Trennschärfe und Stichprobenumfang für einen Test von Anteilen bei einer Stichprobe:

  1. Wählen Sie Statistik: Trennschärfe und Stichprobenumfang: (PSS) Test von Anteilen bei einer Stichprobe. Dieser Menübefehl öffnet den Dialog.
  2. Wählen Sie aus der Liste Berechnen die Option Trennschärfe oder Stichprobenumfang und dann Ihre restlichen Optionen.
  3. Nachdem Sie auf OK geklickt haben, wird ein Analysebericht erstellt.
