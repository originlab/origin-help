Was ist der Statistikmodus?

Der Statistikmodus wurde mit Origin 2025b eingeführt, um Statistikroutinen mehr in den Fokus zu stellen. Er vereinfacht die Origin-Bedienoberfläche, indem ein Großteil der Grafikschaltflächen und der erweiterten Analysewerkzeuge verborgen werden und das Menü Grafikneu strukturiert wird, um statistische Diagramme einfacher navigieren und verwenden zu können. Außerdem werden einige beliebte Statistik-Apps, wie DOE, vorinstalliert.


Da der Statistikmodus nur grundlegende Menüs und Schaltflächen behält, können Sie, falls Sie ein Hilfsmittel nicht über die Bedienoberfläche finden, den Befehl oder den Schaltflächennamen in der Suchleiste neben dem Hauptmenü eingeben, um es zu suchen und auszuführen.

Wie wird der Statistikmodus aktiviert?

  • Statistikmodus während der Installation aktivieren
    Beim Installieren von Origin können Sie das Kontrollkästchen Statistikbedienoberfläche auf der Seite "Zusätzlichen Bedienoberflächenmodus wählen" aktivieren. Das Auswählen der Statistikbedienoberfläche installiert auch eine Reihe von statistischen Apps vor.

    Sobald die Installation vollständig ist, startet Origin standardmäßig im Statistikmodus.
    Hinweis:

    Wenn Sie die Kontrollkästchen Statistik-Bedienoberfläche und Life-Science-Bedienoberfläche während der Installation aktivieren, startet Origin im im Life-Science-Modus. Sie können in den Statistikmodus wechseln, indem Sie im Menü Einstellungen: Bedienoberflächenmodus: Standard wählen.


    Lesen Sie auf dieser Seite eine Schritt-für-Schritt-Anweisung zur Origin-Installation.

  • Wenn Sie Origin mit dem Standardmodus installiert haben,
    können Sie immer in den Statistikmodus wechseln, indem Sie “Origin modifizieren”:
    1. Öffnen Sie das Startmenü von Windows, klicken Sie auf Ihren Origin-Programmordner und wählen Sie Origin 20## reparieren oder deinstallieren.
    2. Wählen Sie auf der Willkommen-Seite Programm ändern .
    3. Klicken Sie auf Weiter, bis Sie die Seite "Zusätzliche Bedienoberflächenmodi wählen“ gelangen, und aktivieren Sie dann das Kontrollkästchen Statistikbedienoberfläche.
    4. Klicken Sie auf Weiter, um die Installation abzuschließen.
    Hinweise:

    Wenn Sie das Kontrollkästchen Statistikbedienoberfläche aktivieren, ist eine der vorinstallierten Apps Design of Experiments (DOE). Diese App erfordert, dass die R-Software in der Version 4.4.1 VOR OriginPro installiert wurde.
    Verwenden Sie diesen Link, um diese spezielle Version von R herunterzuladen.

Wie kehrt man zum Standardmodus zurück?

Sie können jederzeit zum Standardmodus zurückkehren:

  • Wählen Sie im Menü Einstellungen: Bedienoberflächenmodus: Standard.
