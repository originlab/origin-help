Brief Description

A piecewise model that simulates ligand binding using an exponential rise equation and an exponential decay equation.

Sample Curve

Parameter

Number: 6

Names: Hotnm, Kon, Koff, Bmax, Time0, NS

Meanings: Hotnm=radioligand concentration in nM, Kon=association rate constant, Koff=dissociation rate constant, Bmax=max binding capacity, Time0=washout time, NS=nonspecific binding

Lower Bounds: Kon>0, Koff>0

Upper Bounds: none

Derived Parameters

Kd=Koff/Kon
