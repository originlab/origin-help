Datenanforderungen

Wählen Sie mindestens eine Y-Spalte aus. Wenn es (eine) verbundene X-Spalte(n) gibt, stellt/en die X-Spalte(n) die X-Werte bereit; ansonsten wird ein Abtastintervall der Y-Spalte(n) oder Zeilennummer verwendet.

Diagramm erstellen

  1. Wählen Sie die XY-Quellspalte(n).
  2. Wählen Sie im Menü Zeichnen > Einfache 2D: Eingeteiltes Punktdiagramm.

Der Dialog plot_binnedscatter wird geöffnet.

Registerkarte Allgemein

Zu berechnende Größe

Currently, Origin supports to compute the count number and mean values for the XY piceses. If you choose Count, the frequency count will be calculated; if choosing Mean, you have to select another column to calculate the mean values within each piceses.

Spalte zum Berechnen des Mittelwerts

Wählen Sie eine Spalte, um die Mittelwerte zu berechnen, wenn Zu berechnende Eigenschaft auf Mittelwert gesetzt ist.

Seiten teilen nach

Aktivieren Sie dieses Kontrollkästchen, um Gruppierungsspalte(n) auszuwählen und damit die Daten auf verschiedene Diagrammseiten aufzuteilen.

Farbskala teilen

Dieses Bedienelement ist nur für mehrere als Eingabe ausgewählte Spalten verfügbar. Aktivieren Sie dieses Kontrollkästchen, um die gleiche Farbskala innerhalb der verschiedenen Eingabespalten zu teilen.

Registerkarte Klasseneinteilung

Wenn eine Y-Spalte als Eingabe ausgewählt ist, können Sie die Optionen für die X- und Y-Klasseneinteilungen separat festlegen. Wenn mehrere XY-Spalten ausgewählt sind, müssen Sie zuerst entscheiden, ob die verschiedenen XY-Bereiche die X/Y-Klasseneinteilungen teilen sollen.

X/Y-Klassen teilen

Bei mehreren XY-Eingabebereichen müssen Sie entscheiden, ob die verschiedenen X/Y-Spalten die X/Y-Klasseneinteilungen gemeinsam nutzen sollen. Wenn X-Klassen teilen bzw. Y-Klassen teilen aktiviert ist, können Sie die Klasseneinteilung für X- und Y-Spalten festlegen.

Klasseneinteilungstyp

Hier unterstützt Origin zwei Einteilungstypen: Linear bzw. Log10.

Bereich der Klasseneinteilungen festlegen mit

Legen Sie fest, wie der X/Y-Einteilungsbereich definiert wird.

  • Klassenmitten
    Der X/Y-Klasseneinteilungsbereich wird mit Hilfe der Klassenmitten angegeben.
  • Klassenenden
    Der X/Y-Klasseneinteilungsbereich wird mit Hilfe der Klassenenden angegeben.
Minimum des Klassenanfangswerts

Legen Sie das Minimum des Klassenanfangswerts für X/Y fest.

Maximum des Klassenendwerts

Legen Sie das Maximum des Klassenendwerts für X/Y fest.

Schritt nach

Legen Sie die Klassenbildung fest, einschließlich Klassenbreite oder Anzahl der Klassen.

Klassenbreite

Legen Sie die feste Schrittgröße für X/Y-Klassen fest.

Anzahl der Einteilungen

Sie wird automatisch durch den Klasseneinteilungsbereich und das Inkrement erzeugt.

Vorlage

Hinweise

Das eingeteilte Punktdiagramm ist eine Variante der Heatmap. Es verwendet die gleiche Einteilungsmethode wie das Hilfsmittel 2D-Häufigkeitszählung.

Falls die Eingabedaten in Seiten aufgeteilt werden, enthält das Ergebnisblatt mehrere virtuelle Matrizen. Immer jeweils zwei Matrizen werden durch eine leere Spalte getrennt, und die benutzerdefinierte Parameterzeile(n) werden zum Identifizieren der verschiedenen Gruppen hinzugefügt.
