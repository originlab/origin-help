Hilfreiche Informationen

Um den Dialog für den Chi-Quadrat-Test auf Anpassungsgüte zu öffnen:

  1. Wählen Sie bei aktivem Arbeitsblatt Statistik: Hypothesentest: Chi-Quadrat-Test auf Anpassungsgüte.


Siehe auch:

  • Einführung in Chi-Quadrat-Test der Anpassungsgüte


Eingabedatenform

Roh Führen Sie den Test mit Hilfe der Rohdatenspalte für Kategorie durch.

Wenn Sie diese Option auswählen, kann die Spalte Beobachtete Anzahl in der folgenden Tabelle nicht bearbeitet werden. Diese Option ist für den aus der Arbeitsblattspalte importierten Datensatz verfügbar. Wählen Sie eine Rohdatenspalte für Kategorie. Der beobachtete Wert wird automatisch gezählt und in die Tabelle eingegeben. Sie können dann die Erwarteten Daten benutzerdefiniert anpassen.

Zusammengefasst Führen Sie den Test mit Hilfe der zusammengefassten Daten für die beobachtete Anzahl und Erwarteten Daten durch.

Signifikanzniveau

Legen Sie das Signifikanzniveau für den Chi-Quadrat-Test auf Anpassungsgüte fest.

Tabelle zurücksetzen

Löschen Sie den gesamten Inhalt in der folgenden Tabelle.

Tabelle

Geben Sie den Datensatz durch diese zwei zwei Methoden in die Tabelle ein:

  • Geben Sie die Daten direkt in die Tabelle ein.
  • Klicken Sie auf die Schaltfläche im Header, um einen Spaltendatensatz im Arbeitsblatt auszuwählen und zu importieren.
Kategorie Legen Sie den Namen der getesteten Gruppen (Zeilen) fest.
Beobachtete Anzahl Wenn die Eingabedatenform Zusammengefasst ist, kann diese Spalte bearbeitet werden.

Legen Sie die tatsächliche Anzahl des beobachteten Werts für jede Kategorie fest.

Erwartet Legen Sie den erwarteten Wert für jede Kategorie fest.

Klicken Sie auf die Auswahlliste unter Erwartet im Spaltenheader. Sie können den Typ der erwarteten Daten ändern. Die erwarteten Daten sollte einem der folgenden Typen entsprechen:

  • Gleicher Anteil (1/k)
Wenn Sie diese Option auswählen, muss der erwartete Wert nicht eingegeben werden. Er wird automatisch berechnet mit 1 geteilt durch die Anzahl der zu testenden Kategorien (Zeilen).
  • Anteil (0-1)
Die Summe der erwarteten Fraktion muss 1 ein.
  • Anzahlen
Die Gesamtheit der beobachteten Anzahl und der erwarteten Anzahl muss gleich sein.
  • Prozentanteil (%)
Die Summe der erwarteten Prozentanteile muss gleich 100 ein.
