Tabellentypen

Freiform (Arbeitsblatt)

Origin-Standardarbeitsblatt Keine Struktur Weitere Einzelheiten finden Sie auf dieser Seite.

XY

Dieser Tabellentyp folgt der Struktur XYYY...: eine einzelne X-Spalte gepaart mit mehreren Y-Spalten. Er kann eine optionale Spalte Zeilentitel (Textspalte zum Beschriften von Zeilen) und eine Spalte für den X-Fehler enthalten. Jeder Y-Datensatz stellt eine eindeutige Gruppe mit mehreren Replikaten dar.

Datenformat Wählen Sie das Format der Tabellendaten:
  • Rohdaten
  • Zusammenfassung (Mittelwert)
  • Zusammenfassung (Median)
Anzahl der Gruppen (Y-Datensätze) Wählen Sie oder geben Sie die Anzahl der zu vergleichenden Gruppen ein. Jeder Y-Datensatz hat die gleiche Anzahl von replizierten Spalten.

Hinweis: Sie können Datensätze jederzeit nach Erstellen der Tabelle hinzufügen oder entfernen.

  • Um Gruppen und Replikate zu rekonstruieren, klicken Sie auf das Tabellensymbol und wählen Sie im Menü Tabelle neu strukturieren. Einzelheiten lesen Sie bitte in diesem Abschnitt.
  • Um einen neuen Y-Datensatz hinzuzufügen, klicken Sie auf die Schaltfläche Neue Spalten anhängen auf der Symbolleiste.
  • Um einen neuen Y-Datensatz einzufügen, klicken Sie mit der rechten Maustaste auf die Titelleiste des Datensatzes und wählen Sie Einfügen.
  • Um einen Y-Datensatz zu löschen, klicken Sie mit der rechten Maustaste auf die Titelleiste des Datensatzes und wählen Sie Löschen.
Gruppennamen Geben Sie mit Semikolon getrennte Namen für Gruppen (Y-Datensätze) ein.
Zeilentitel Aktivieren Sie dieses Kontrollkästchen, um eine Textspalte für Zeilenbeschriftungen hinzuzufügen.
X-Fehler Aktivieren Sie dieses Kontrollkästchen, um eine Fehlerbalkenspalte für X hinzuzufügen.
Werte pro Gruppe replizieren Wählen Sie oder geben Sie die Anzahl der replizierten Teilspalten pro Y-Datensatz ein. Geben Sie 1 für keine Replikationen ein.

Hinweis: Sie können Datensätze jederzeit nach Erstellen einer Teilspalte hinzufügen oder entfernen.

  • Um eine Teilspalte einzufügen, klicken Sie auf die Zelle Name einer Teilspalte, um diese Replikation auszuwählen, mit der rechten Maustaste zu klicken und Einfügen auszuwählen. Es wird eine neue Replikation zu allen Datensätzen an der gleichen Position hinzugefügt.
  • Um eine vorhandene Teilspalte aus allen Datensätzen zu löschen, klicken Sie auf die Zelle Name einer Teilspalte, um diese Replikation auszuwählen, mit der rechten Maustaste zu klicken und Löschen auszuwählen.
X-Titel Beschriftung, die für den Titel der X-Spalte verwendet wird


XY-Tabellen finden breite Anwendung bei experimentellen Daten, beispielsweise bei Dosis-Wirkungs- oder Hemmungstests, bei denen eine gemessene Variable und mehrere Ergebnisgrößen vorliegen.

Spalte

Dieser Tabellentyp folgt der Struktur YYY...: mehrere Y-Spalten und keine X-Spalte. Jede Y-Spalte stellt eine unabhängige Gruppe dar, und Replikationen werden in jeder Spalte angeordnet. Er kann eine optionale Spalte Zeilentitel (Textspalte zum Beschriften von Replikationen) enthalten.

Anzahl der Gruppen Wählen Sie oder geben Sie die Anzahl der zu vergleichenden Gruppen ein. Eine Y-Spalte pro Gruppe

Hinweis: Sie können Y-Spalten (Gruppen) jederzeit nach Erstellen der Tabelle hinzufügen oder entfernen.

  • Um eine neue Spalte hinzuzufügen, klicken Sie auf die Schaltfläche Neue Spalten anhängen auf der Symbolleiste.
  • Um eine neue Spalte vor eine vorhandenen Spalte einzufügen, klicken Sie mit der rechten Maustaste auf die Titelleiste des Datensatzes und wählen Sie Einfügen.
  • Um eine Spalte zu löschen, klicken Sie mit der rechten Maustaste auf die Titelleiste der Spalte und wählen Sie Löschen.
Gruppennamen Geben Sie mit Semikolon getrennte Namen für Gruppen (Y-Spalten) ein.
Zeilentitel Aktivieren Sie dieses Kontrollkästchen, um eine Textspalte für Zeilenbeschriftungen hinzuzufügen.


Spaltentabellen werden hauptsächlich für Rohdaten von einfachen ANOVA und anderen Analysen verwendet, die unabhängige Gruppen gemessen an der gleichen Variable vergleichen (z. B. t-Tests, nicht-parametrische Tests).

Gruppiert

Dieser Tabellentyp folgt der Struktur Zeilentitel + Y-Spalten: eine Titelspalte für Zeilenbeschriftungen, gefolgt von mehreren Y-Spalten, die in Gruppen organisiert sind. Jede Gruppe stellt eine Stufe des Faktors A dar und die Y-Spalten innerhalb jeder Gruppe stellen die Stufen des Faktors B dar.

Optional können Sie Teilgruppen aktivieren, um den dritten Faktor für die dreifache ANOVA hinzuzufügen. Teilgruppen teilen jede Gruppe (Faktor A) in zusätzliche Stufen, die Faktor B darstellen, während die Y-Spalten innerhalb jeder Teilgruppe Faktor C darstellen.

Beachten Sie, dass alle Faktoren (einfache und zweifache) gekreuzt sind (alle Kombinationen präsent).

Anzahl der Gruppen Wählen Sie oder geben Sie die Anzahl der zu vergleichenden Gruppen über zwei (oder drei) kategoriale Dimensionen ein.

Hinweis: Sie können Gruppen jederzeit nach Erstellen der Tabelle hinzufügen oder entfernen.

  • Um Gruppen und Replikate zu rekonstruieren, klicken Sie auf das Tabellensymbol und wählen Sie im Menü Tabelle neu strukturieren. Einzelheiten lesen Sie bitte in diesem Abschnitt.
  • Um eine neue Gruppe hinzuzufügen, klicken Sie auf die Schaltfläche Neue Spalten anhängen auf der Symbolleiste.
  • Um eine neue Gruppe vor einer vorhandenen Gruppe einzufügen, klicken Sie mit der rechten Maustaste auf die Titelleiste des Datensatzes und wählen Sie Einfügen.
  • Um eine Gruppe zu löschen, klicken Sie mit der rechten Maustaste auf die Titelleiste der Gruppe und wählen Sie Löschen.
Gruppennamen Geben Sie Namen der Gruppen mit Semikolon getrennt ein.
Anzahl der Teilgruppen Bei der dreifachen ANOVA wählen Sie oder geben Sie unter Anzahl der Teilgruppen einen Wert ein, der nicht 0 ist, um den dritten Faktor hinzuzufügen. Teilgruppen teilen jede Gruppe in zusätzliche Stufen, die Faktor B darstellen, während die Y-Spalten innerhalb jeder Teilgruppe Faktor C darstellen. Dies erstellt einen gekreuzten Versuchsplan mit drei Faktoren, wobei Faktor A (Gruppen), Faktor B (Teilgruppen) und Faktor C (Y-Spalten) alle miteinander gekreuzt sind.
Werte pro Gruppe replizieren Wählen Sie oder geben Sie die Anzahl der replizierten Y-Spalten pro Gruppe ein. Geben Sie 1 für keine Replikationen ein.

Hinweis: Sie können eine Y-Spalte jederzeit nach Erstellen der Tabelle hinzufügen oder entfernen.

  • Um eine Y-Spalte einzufügen, klicken Sie auf die Zelle Name einer Y-Spalte, um diese einzelne Spalte auszuwählen, mit der rechten Maustaste zu klicken und Einfügen auszuwählen. Es wird eine neue Replikation zu allen Gruppen an der gleichen Position hinzugefügt.
  • Um eine vorhandene Y-Spalte aus allen Gruppen zu löschen, klicken Sie auf die Zelle Name einer Y-Spalte, um diese einzelne Spalte auszuwählen, mit der rechten Maustaste zu klicken und Löschen auszuwählen.
Zeilentitel Aktivieren Sie dieses Kontrollkästchen, um eine Textspalte für Zeilenbeschriftungen hinzuzufügen.


Gruppierte Tabellen werden hauptsächlich für zweifache ANOVA und Analysen mit zwei unabhängigen kategorialen Variablen (Faktoren) verwendet. Jeder Faktor hat zwei oder mehr Stufen.

Kontingenz

Dieser Tabellentyp folgt einer zweifachen Kontingenzstruktur: eine Textspalte für Zeilenkategoriebeschriftungen, gepaart mit mehreren numerischen Spalten, die Häufigkeitsanzahlen enthalten. Die erste Textspalte enthält Beschriftungen für die erste kategoriale Variable. Die folgenden numerischen Spalten enthalten ganzzahlige Anzahlen für jede Stufe der zweiten kategorialen Variable.

Spaltenkategorien Geben Sie mit Semikolon getrennte Beschriftungen für die zweite kategoriale Variable ein.


Die Kontingenztabellen sind für kategoriale Datenanalysen, wie dem Chi-Quadrat-Test und dem exakten Test nach Fisher, entwickelt worden.

Lebensdauer

Dieser Tabellentyp folgt der Struktur Zeit+ Status: eine X-Spalte für die abgelaufene Zeit, gepaart mit einer oder mehreren Y-Spalten für den Ereignisstatus. Die X-Spalte enthält die "abgelaufene Zeit" ab Beginn der Beobachtung bis zum Ereignis oder zur Zensierung. Die Y-Spalten enthalten den "Status", der angibt, ob ein Ereignis eingetreten ist: typiscerweise ist 0 = Zensiert (kein Ereignis/zurückgezogen), 1 = Ereignis (Tod/Fehlschlag/festgelegtes Ergebnis ist aufgetreten). Eine optionale Spalte für Zeilentitel kann für einzelne Subjektbeschriftungen hinzugefügt werden.

Anzahl der Gruppen Wählen Sie oder geben Sie die Anzahl der zu vergleichenden Gruppen ein. Eine Y-Spalte pro Gruppe

Hinweis: Sie können Gruppen (Y-Spalten) jederzeit nach Erstellen der Tabelle hinzufügen oder entfernen.

* Um eine neue Spalte hinzuzufügen, klicken Sie auf die Schaltfläche Neue Spalten anhängen  auf der Symbolleiste.
  • Um eine neue Spalte vor eine vorhandenen Spalte einzufügen, klicken Sie mit der rechten Maustaste auf den Datensatz und wählen Sie Einfügen.
  • Um eine Spalte zu löschen, klicken Sie mit der rechten Maustaste auf die Spalte und wählen Sie Löschen.
Gruppennamen Geben Sie mit Semikolon getrennte Namen für Y-Spalten ein.
Zeilentitel Aktivieren Sie dieses Kontrollkästchen, um eine Textspalte für Subjektbeschriftungen hinzuzufügen.
Abgelaufene Zeit in Standardmäßig ist die Einheit der “Abgelaufenen Zeit” (X-Spalte) “Tage”. Verwenden Sie dieses Bearbeitungsfeld, um die Einheiten, Monate, Jahre, etc. zu ändern.

Zusammenfassungsdaten & Zusammenfassungsdaten zeichnen

Wählen Sie das Zeichnen der statistischen Zusammenfassungsdaten entweder als Punkt-, Linien-, Punkt-Linien- oder Säulendiagramm. Y-Werte könne sein: Mittelwert, Median, Geometrische Mittelwert und Harmonisches mit optionalen Fehlerbalken aus Standardabweichung, SEM (Standardfehler des Mittelwerts), 95%-KI (Oberes 95% KI des Mittelwerts - Unteres 95% KI des Mittelwerts) oder Bereich (Max.-Min.).

Die Zusammenfassungsdaten werden in einem Arbeitsblatt "Summary Stats" (Zusammenfassungsstatistk) ausgegeben. Sie können auch wählen, die Gesamtanzahl N auszugeben.

Normalisieren

Skalieren Sie die Daten neu auf eine allgemeine relative Skala, 0 % bis 100 % oder 0,0 bis 1,0, um gruppen- bzw. teilspaltenübergreifende Vergleiche anzustellen.

Teilspalten Legen Sie fest, wie die Teilspalten in den Gruppen beim Normalisieren behandelt werden sollen.
  • Teilspalten nach Gruppe normalisieren: Alle Teilspalten innerhalb der Gruppe werden zusammen mit Hilfe der Statistik auf Gruppenebene (Zeilenmittelwerte) normalisiert.
  • Jede Teilsalte separat normalisieren: Jede Teilspalte wird einzeln mit Hilfe ihrer eigenen Werte normalisiert.
0 % ist definiert als Legen Sie fest, wie 0 % definiert ist:
  • Falls Teilspalten nach Gruppe normalisieren gilt, definieren Sie 0 % als Kleinster Zeilenmittelwert, Erster Zeilenmittelwert (oder letzter, je nachdem welcher kleiner ist) oder Fester Wert, festgelegt im Bearbeitungsfeld 0 % festgelegt bei.
  • Falls Jede Teilspalte separat normalisieren gilt, definieren Sie 0 % als Kleinster Wert in jeder Teilspalte, Erster Wert in jeder Teilspalte (oder letzter, je nachdem welcher kleiner ist) oder Fester Wert, festgelegt im Bearbeitungsfeld 0 % festgelegt bei.
100 % ist definiert als Legen Sie fest, wie 100 % definiert ist:
  • Falls Teilspalten nach Gruppe normalisieren gilt, definieren Sie 100 % als Größter Zeilenmittelwert, Letzter Zeilenmittelwert (oder erster, je nachdem welcher größer ist), Fester Wert, festgelegt im Bearbeitungsfeld 0 % festgelegt bei, Summe aller Zeilenmittelwerte oder Durchschnitt aller Zeilenmittelwerte.
  • Falls Jede Teilspalte separat normalisieren gilt, definieren Sie 100 % als Größter Wert in jeder Teilspalte, Letzter Wert in jeder Teilspalte (oder erster, je nachdem welcher größer ist), Fester Wert, festgelegt im Bearbeitungsfeld 100 % festgelegt bei, Summe der Werte in jeder Teilspalte oder Durchschnitt der Werte in jeder Teilspalte.
Ergebnisse zeigen als Legen Sie das Ausgabeformat der normalisierten Daten fest.
  • Brüche: Dezimalwert von 0,0 bis 1,0
  • Prozente: Prozente von 0 % bis 100 %

X transformieren

Transformieren Sie die Konzentrationswerte (X-Daten) für die Dosis-Wirkungs-Analyse. Dies ist typischerweise ein erforderlicher Vorverarbeitungsschritt für die sigmoidale Dosis-Wirkungs-Kurvenanpassung.

X = 0 mit anderem Wert ersetzen Wenn X null Konzentrationen enthält (z. B. Fahrzeugkontrollen), aktivieren Sie dieses Kontrollkästchen, um "0" mit einem festgelegten kleinen Wert zu ersetzen. Vor der Log-Transformation erforderlich, da log(0) undefiniert ist.

Geben Sie den Ersatzwert im Bearbeitungsfeld Wert, um X = 0 zu ersetzen ein. Eine gängige Praxis ist es, 0 mit 1/10 der niedrigsten Konzentration, die nicht Null ist, zu ersetzen.

Einheiten ändern Wandeln Sie die Konzentrationseinheiten durch Multiplikation oder Division um.

Wählen Sie Kein, um die Einheiten nicht umzuwandeln. Wenn Multiplizieren oder Dividieren ausgewählt ist, geben Sie den Faktor im Bearbeitungsfeld Anzuwendende Konstante ein. Um beispielsweise "uM" in "mM“ umzuwandeln, wählen Sie Dividieren und 1000 in Anzuwendende Konstante.

In Logarithmen transformieren Wandeln Sie die linearen X-Werte für eine sigmoidale Kurvenanpassung auf eine Log-Skalierung um.

Wählen Sie den Logarithmus aus der Auswahlliste Basis des Logarithmus: Log10 (Basis 10), ln (Basis e) und Log2 (Basis 2).

Nichtlinearer Fit

Führen Sie eine nichtlineare Kurvenanpassung auf XY-Daten durch. Es wird zuerst ein einfacher Dialog geöffnet, auf dem Sie eine Anpassungsfunktion auswählen können. Durch Klicken auf OK wird dann der Dialog NLFit aufgerufen, über den Sie den Anpassungsprozess vollständig steuern können.

Funktion auswählen Lesen Sie in dieser Funktionsliste ausführliche Informationen (Hinweis: Die verfügbare Kategorie unterscheidet sich vom Standardmodus). Klicken Sie auf die Schaltfläche , um die von Ihnen benötigte Funktion zu suchen.
Anpassungsmethode Legen Sie fest, ob mit den Rohdaten oder der Zusammenfassungsstatistik angepasst werden soll: Mittelwert + StdAbw. (StdAbw. als Gewichtungsfaktor verwendet), Mittelwert + SE (SE als Gewichtungsfaktor verwendet) oder Nur Mittelwert. Falls Zusammenfassungsstatistik ausgewählt ist, wird automatisch ein Arbeitsblatt "Summary Stats" erzeugt und als Eingabedaten verwendet.

Hinweis: Falls das Hilfsmittel Nichtlineare Kurvenanpassung über ein Zusammenfassungsdiagramm geöffnet wird, wird keine Gewichtung unterstützt, auch wenn die Zeichnung Fehlerbalken enthält.

Globaler Fit Aktivieren Sie dieses Kontrollkästchen, um die Parameter der Anpassungsfunktion über alle Datensätze (Gruppen) gemeinsam zu nutzen, wodurch sich die Parameterwerte für alle Datensätze ergeben.

Deaktivieren Sie diese Option, um jeden Datensatz unabhängig anzupassen und separate Ergebnisse für jeden Datensatz zu erhalten (auch wenn sie in einem Bericht kompiliert werden).

Lesen Sie auf dieser Seite die Einzelheiten zur globalen Anpassung.

EC50/IC50-Linien hinzufügen Verfügbar für bestimmte Funktionen wie Boltzmann, DoseResp, Hill, Hill1, Logistic, Logistic5, MichaelisMenten etc.
Ausreißer entfernen (Robuste Regression) Aktivieren Sie dieses Kontrollkästchen, um Umgang mit Ausreißern festzulegen und damit die Ausreißer beim Anpassen der Kurve zu entfernen.

Lineare Anpassung

Führen Sie eine lineare Regression für die XY-Daten durch. Jede Gruppe wird unabhängig angepasst, und alle Anpassungsergebnisse werden in einem Bericht kompiliert. Der Dialog Lineare Anpassung wird aufgerufen, über den Sie den Anpassungsprozess vollständig steuern können.

Anpassungsmethode Legen Sie fest, ob mit den ursprünglichen Daten oder den Zusammenfassungsdaten angepasst werden soll.
  • Rohdaten
    Jede Gruppe wird unabhängig angepasst. Replikationen innerhalb jeder Gruppe werden als ein Datensatz zusammengefasst und angepasst.
  • Mittelwert + StdAbw. / Mittelwert
    Ein Arbeitsblatt "Summary Stats" wird automatisch erzeugt, um den Mittelwert und die Standardabweichung der Replikationen in jeder Gruppe zu berechnen. Jede Gruppe wird dann mit Hilfe des Mittelwerts als Eingabe unabhängig angepasst. Falls Mittelwert + StdAbw. Ausgewählt ist, wird die inverse Varianz (1/SD^2) als Gewichtung angewendet.
Fester Schnittpunkt mit der Y-Achse Beschränken Sie den Schnittpunkt mit der Y-Achse auf den in Fester Schnittpunkt mit der Y-Achse bei festgelegten Wert.
Test auf fehlende Anpassung Aktivieren Sie diese Option, um die Ergebnisse der "fehlenden Anpassung" für replizierte Daten auszugeben, die verwendet werden, um die Modelleignung zu bewerten.

Prism-Dateien importieren

  • Die einfachste Methode ist, eine Prism-Datei (.pzfx, .prism, .prismt, .xml) per Drag&Drop in den Origin-Arbeitsbereich zu ziehen.
    Origin überträgt alle Datentabellen und die Analyseergebnisse aus der Prism-Datei in eine Origin-Arbeitsmappe.
  • Datei: Prism öffnen, um die Prism-Dateien in Origin direkt zu öffnen.
    Ein Unterschied zwischen Drag&Drop und Öffnen ist, dass Sie beim Öffnen die Option haben, auszuwählen, welche Tabellen importiert werden sollen.
    Hinweis: Wenn die gleiche Datei bereits in Prism geöffnet ist, müssen Sie sie in Prism schließen, bevor sie in Origin geöffnet wird.
  • Daten: Mit Datei verbinden: Prism, um eine Prism-Datei über den Prism-Konnektor zu importieren.
  • Wenn Prism immer noch auf Ihrem PC ausgeführt wird, können Sie die Daten aus Prism kopieren und direkt in Origin einfügen. Das heißt, Sie wählen eine Tabelle in Prism, kopieren sie, gehen dann zu Origin und zu einem regulären (Freiform) Arbeitsblatt und fügen die Daten ein. Origin wird die Datenstruktur automatisch erkennen und das Arbeitsblatt in den für die Daten korrekten Tabellentyp konvertieren.
