Brief Description

Dose-response curve with variable Hill slope and absolute IC50.

Sample Curve

Parameter

Number: 5

Names: A1, A2, LogIC50, p, B

Meanings: A1=Bottom asymptote, A2=Top asymptote, LogIC50=Logarithm of concentration for response at half between top and baseline, p=Hill slope, B=Maximally inhibited response

Lower Bounds: none

Upper Bounds: none

Derived Parameters

IC50=10^LogIC50
