Function


Brief Description

Dose-response curve with variable Hill slope and EC at any percent.

Sample Curve

Parameter

Number: 5

Names: LogECF, F, A1, A2, p

Meanings: LogECF= Logarithm of EC for percent F, F=Percent of response for EC, A1=Bottom asymptote, A2=Top asymptote, p=Hill slope

Lower Bounds: F>0

Upper Bounds: F<100

Derived Parameters

ECF=10^LogECF

Span=A2 - A1

Script Access

nlf_DoseRespEC(x,LogECF,F,A1,A2,p)
