Brief Description

Dose-response curve with variable Hill slope and EC50 shift by ratio.

Sample Curve

Parameter

Number: 5

Names: LogEC50, ratio, A1, A2, p

Meanings: LogEC50=Logarithm of EC50 for agonist, ratio=Ratio of EC50 for inhibitor to agonist alone, A1=Bottom asymptote, A2=Top asymptote, p=Hill slope

Lower Bounds: none

Upper Bounds: none

Derived Parameters

EC50=10^LogEC50

Script Access

nlf_DoseRespShift(x,LogEC50,ratio,A1,A2,p)
