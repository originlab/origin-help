Signifikanzniveau

Legen Sie das Signifikanzniveau für den Test auf gleiche Varianzen fest.

Normalverteilung annehmen

  • Falls diese Option deaktiviert ist, werden die Methoden Mehrfache Vergleiche nach Bonett, Brown-Forsythe, Levene (Quadrierte Abweichungen) und Levene (Absolute Abweichungen) im Test verwendet und der p-Wert für sie ausgegeben. Das Diagramm Vergleichsintervalle für StdAbw. gibt den grafischen Zusammenfassungsbericht aus.
  • Falls diese Option aktiviert ist, wird der F-Test für die Daten mit zwei Gruppen oder die Bartlett-Methode für die Daten mit drei oder mehr Gruppen verwendet und der p-Wert ausgegeben. Das Diagramm 95% Bonferroni-Konfidenzintervalle für StdAbw. wird im grafischen Zusammenfassungsbericht ausgegeben, und das Wahrscheinlichkeitsdiagramm mit Normalverteilung wird im Zweig Diagnosec gezeigt.

Ausgabe

Hilfe zum Festlegen der Bereiche finden Sie unter: Ergebnisse ausgeben

Grafischer Zusammenfassungsbericht Erstellen Sie einen Zusammenfassungsbericht, einschließlich Balken für den p-Wert und die Effektgröße sowie ein Datenverteilungsdiagramm. Es werden auch die Ergebnistabellen an das Diagramm angehängt, um die statistischen Werte zu zeigen.

Die Fußnote nach dem Zusammenfassungsdiagramm diagnostiziert diese statistischen Ergebnisse.

Grafischer Diagnosebericht Legen Sie fest, ob der grafische Diagnosebericht angezeigt werden soll.

Das Verlaufsdiagramm zum Erkennen von Ausreißern und das Einzelwertdiagramm für die Verteilung werden in diesem Bericht gezeigt.

Wenn Normalverteilung annehmen (auf der Registerkarte Eingabe) ausgewählt ist, wird das Wahrscheinlichkeitsdiagramm mit Normalverteilung im Zweig Diagnose gezeigt.
