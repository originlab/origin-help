Einführung

Dieses Hilfsmittel erstellt einen grafischen Zusammenfassungsbericht aus Daten, einschließlich Gruppeninformationen. Die Statistikdiagramme umfassen Histogramme, Boxdiagramme und Diagramme der Konfidenzintervalle mitsamt den Tabellen der statistischen Schlüsseleigenschaften.

Grafische Zusammenfassung durchführen

  1. Wählen Sie die Eingabedatenspalten, für die Sie deskriptive Statistiken berechnen möchten.
  2. Wählen Sie Statistik: Deskriptive Statistik: Grafische Zusammenfassung, um den Dialog zu öffnen.
  3. Wählen Sie die Gruppierungsspalte(n) für Gruppe(n), geben Sie das gewünsche Konfidenzniveau im Bearbeitungsfeld Konfidenzniveau (%) ein und legen Sie dann das Diagrammlayout über die Auswahlliste Diagrammanordnung fest.
  4. Klicken Sie auf OK, um eine deskriptive Statistik durchzuführen und die Diagramme zu erstellen.

Bedienelemente des Dialogs

Eingabe Wählen Sie die Eingabespalte(n). Beachten Sie, dass die Datentabelle auch unterstützt wird.
Gruppen Wählen Sie die Spalte(n), um die Eingabedaten in mehrere Gruppen aufzuteilen.
Kondenzintervall (%) Legen Sie das Konfidenzniveau fest.
Diagrammanordnung Legen Sie fest, wie die Statistikdiagramme angeordnet werden.
  • Separate Grafiken:
Jede Variable für jede Gruppe wird in eine separate Grafik gezeichnet. Jede Grafik enthält drei Zeichnungen - ein Histogramm mit Verteilungskurve, ein Konfidenzintervalldiagramm und ein Wahrscheinlichkeitsdiagramm - sowie drei Tabellen - "Deskriptive Statistik", "##% Konfidenzintervalle" und "Test auf Normalverteilung". Der Grafiktitel zeigt die Variable und die Gruppeninformation.
  • Pro Variable:
Jede Variable wird in eine separate Grafik gezeichnet. Die Gruppen werden in verschiedene vertikale Felder gezeichnet. Jede Variable enthält drei Zeichnungen - ein Histogramm mit Verteilungskurve, ein Boxdiagramm mit Ausreißern und ein Konfidenzintervalldiagramm - sowie eine Tabelle, die die Ergebnisse nach Zeile zusammenfasst und die Statistiken für jede Gruppe zeigt.
  • Pro Gruppe:
Jede Gruppe wird in eine separate Grafik gezeichnet. Die Variablen werden in verschiedene vertikale Felder gezeichnet. Jede Gruppe enthält drei Zeichnungen - ein Histogramm mit Verteilungskurve, ein Boxdiagramm mit Ausreißern und ein Konfidenzintervalldiagramm - sowie eine Tabelle, die die Ergebnisse nach Zeile zusammenfasst und die Statistiken für jede Variable zeigt.
  • Alle in einer Grafik:
Alle Variablen und alle Gruppe werden in einer Grafik gezeichnet. Jeder Teildatensatz (Gruppe*Variable) wird in verschiedene vertikale Felder gezeichnet. Jede Grafik enthält Histogramme mit Verteilungskurve, Boxdiagramme mit Ausreißern, Konfidenzintervalldiagramme und eine Tabelle, die die Ergebnisse nach Zeile zusammenfasst und die Statistiken für jeden Teildatensatz zeigt.
