Datenanforderungen

Wählen Sie XY-/XYZ-Spalten/virtuelle Matrix (Block von Arbeitsblattzellen)/Matrix aus, um ein Hexbin-Diagramm zu zeichnen.

Diagramm erstellen

Wählen Sie die gewünschten Daten aus.

Wählen Sie im Menü Zeichnen > Kontor, Heatmap: Hexbin, um den Dialog plot_heatmapxy oder plot_heatmapxyz oder plotvm zu öffnen.

Bitte beachten Sie, dass kein Dialog geöffnet wird, wenn die Eingabedaten sich in einem Matrixblatt befinden, und das Hexbin-Diagramm direkt erstellt wird.

Spezielle Bedienelemente für Hexbin

Regelmäßige Sechsecke bevorzugen

Dieses Kontrollkästchen ist standardmäßig aktiviert. Es gibt zwei Optionen: Y von X ableiten und X von Y ableiten

  • Aktivieren Sie die Optionsgruppe, wenn Regelmäßige Sechsecke bevorzugen ausgewählt ist. Andernfalls deaktivieren Sie sie. Wählen Sie Y von X ableiten per Standard.
  • Wenn Y von X ableiten ausgewählt wurde: Behalten Sie die X-Einteilung bei und leiten Sie die Y-Einteilung an: new_ny = int(round(nx / sqrt(3))); deaktivieren Sie die Optionen der Y-Einteilung, einschließlich Zentrum Min., Zentrum Max., Klassenabstände und Klassenanzahl.
  • Wenn X von Y ableiten ausgewählt wurde: Behalten Sie die Y-Einteilung und leiten Sie die X-Einteilung ab :new_nx = int(round(ny * sqrt(3))); deaktivieren Sie die Optionen der X-Einteilung, einschließlich Zentrum Min., Zenrtrum Max., Klassenabstände und Klassenanzahl.

Vorlage

Hexbin.OTPU (installiert im Origin-Programmordner)

Hinweise

Ein Hexbin-Diagramm, eine Variante der Heatmap, ist ein Typ des zweidimensionalen Histogramms, wobei die Einteilungen hexagonal sind und die Farbe die Anzahl der Datenpunkte innerhalb jeder Klasse darstellt.
