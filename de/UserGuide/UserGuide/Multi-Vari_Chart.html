Datenanforderungen

Wählen Sie eine oder mehrere Y-Spalte(n) mit bis zu vier Faktorspalten.

Diagramm erstellen

Um ein Multi-Vari-Diagramm zu erstellen:

  1. Markieren Sie mindestens eine Arbeitsblattspalte (oder einen Bereich aus einer Spalte).
  2. Wählen Sie Zeichnen > Statistisch: Multi-Vari-Diagramm, um den Dialog plot_multivari zu öffnen.

Der Dialog plot_multivari

Daten

Wählen Sie die Spalte für die Eingabedaten. Es ist nur die Auswahl von einer Spalte zugelassen.

Faktoren

Wählen Sie mehrere Faktoren in Reihenfolge. Sie können mehrere Spalten auswählen, aber die Anzahl der Spalten sollte kleiner als 4 sein. Das Ausklappmenü wird deaktiviert, wenn bereits 4 Spalten ausgewählt sind.

Mittelwert verbinden für 1. Faktor

Legen Sie fest, ob die Mittelwertpunkte für den ersten Faktor verbunden werden sollen. Diese Option ist standardmäßig aktiviert.

Mittelwert verbinden für 2. Faktor

Legen Sie fest, ob die Mittelwertpunkte für den zweiten Faktor verbunden werden sollen. Diese Option ist standardmäßig aktiviert. Sie ist deaktiviert, wenn es nur 1 Faktor gibt.

Mittelwert verbinden für 3. Faktor

Legen Sie fest, ob die Mittelwertpunkte für den dritten Faktor verbunden werden sollen. Diese Option ist standardmäßig aktiviert. Sie ist deaktiviert, wenn es nur 2 Faktoren gibt.

Einzelne Datenpunkte zeigen

Legen Sie fest, ob die einzelnen Punkte gezeigt werden sollen. Wenn die Option aktiviert ist, ist der Boxtyp für alle Boxdiagramme auf Box+Datenüberschneidung und der Boxstil auf Keine Box gesetzt. Dieses Kontrollkästchen ist standardmäßig deaktiviert.

Gesamtmittelwert zeigen

Legen Sie fest, ob der Gesamtmittelwert als eine Referenzlinie bei Mean(plotdata(*,y)) gezeigt werden soll. Dieses Kontrollkästchen ist standardmäßig deaktiviert.

Vorlage

Per Standard wird die Vorlage „multivari“ verwendet, wenn das Kontrollkästchen Auto aktiviert ist. Sie können das Kontrollkästchen Auto deaktivieren, um die Vorlage zu verwenden, die Sie im Voraus vorbereitet haben.

Vorlage

multivari.otpu (installiert im Origin-Programmordner)

Notizen

Ein Multi-Vari-Diagramm zeigt die Mittelwerte bei jeder Faktorebene für jeden Faktor an. Es handelt sich dabei um ein Diagramm mit mehreren Boxen und Verbindungslinien zwischen den Mittelwertpunkten. Jedes Boxdiagramm hat die Einstellungen Boxstil = Keine Box, Whiskerbereich = Kein, Mittelwertperzentil zeigen, Mittelwerte verbinden.

Beispiel

In diesem Beispiel wählen wir 3 Faktoren aus: "Engine Information.Driveline", "Identification.Classification" und "Identification.Year"(markiert mit einer roten Box). Wählen Sie sie als Faktor im Dialog plot_multivari.

Entstapeln Sie die Spalte der Quelldaten mit Faktor 1 und Faktor 2, einschließlich Spaltenfaktor 3 (markiert mit einer rosa Box). Bei 8 entstapelten Spalten werden die Boxdiagramme nur mit verbundenen Mittelwertpunkten gezeichnet (gelb gefüllte Punkte + schwarze Linie). Setzen Sie im Dialog Details Zeichnung den Faktor 2 als die Untergruppierung auf der Registerkarte Gruppe und den Faktor 3 als die Spalte unter Horizontales Feld auf der Registerkarte Feld.

Berechnen Sie die Mittelwerte für die Teilgruppen (markiert mit einer blauen Box) und verschiedene Felder (markiert mit einer grünen Box) und zeichnen Sie sie als Punkt-Liniendiagramme, um diese Mittelwerte darzustellen.
