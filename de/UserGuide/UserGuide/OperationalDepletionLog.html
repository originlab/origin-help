Brief Description

Sample Curve

Parameter

Names: logKa, logtau, n, B, Em

Meanings: logKa=log of receptor dissociation constant, logtau=log of transducer constant tau, n=Transducer slope, B=Response in absence of agonist, Em=Maximum response

Lower Bounds: none

Upper Bounds: none

Derived Parameters

Tau=10^logtau
