Brief Description

Piecewise linear function with two segments and gentle connection.

Sample Curve

Parameter

Number: 5

Names: a, k1, x0, k2, s

Meanings: a=Intercept,k1=Slope for first segment, x0=X value at intersection, k2=Slope for second segment, s=Sharpness for the bend

Lower Bounds: s>0

Upper Bounds: none

Script Access

nlf_PWL2Hinge(x,a,k1,x0,k2,s)
