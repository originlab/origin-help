Analyse in Datentabelle

Die meisten Analysehilfsmittel sind über das Hauptmenü Analyse verfügbar.

Einige Tabellentypen, wie XY- und Spaltentabellen, bieten einen schnellen Zugriff auf häufig verwendete Analysen wie Normalisierung und Regression.

Statistik in Datentabelle

Die meisten Statistikhilfsmittel sind über das Hauptmenü Statistik erreichbar.

Für die am häufigsten verwendeten Hilfsmittel kann der Life-Science-Modus die geeigneten Eingabedaten aus der Tabelle (sogar für die Y-Zusammenfassungstabelle) auswählen. Einige Hilfsmittel bietet einen Dialog für einen Schnellstart, um Ihren Analyseworkflow zu vereinfachen. Der Dialog mit sämtlichen Funktionen wird dann geöffnet und gewährt Ihnen die vollständige Kontrolle, während Ihr Workflow optimiert wird.

Statistik für gesamtes Blatt

  1. Wählen Sie im Menü Statistik: Deskriptive Statistik: Statistik für gesamtes Blatt.
  2. Wählen Sie im aufgerufenen Dialog, wie Sie die Eingabedaten anordnen möchten:
    Replikationen vor Analyse mitteln Mitteln Sie die Werte in jeder Zeile (Ausgabe in Arbeitsblatt "Summary Stats") und berechnen Sie dann die Statistiken der gemittelten Werte.
    Jede Teilspalte separat analysieren Berechnen Sie die Statistiken für jeden Unterordner unabhängig.
    Teilspalten vor Analyse zusammenfassen Stapeln Sie alle Teilspaltenwerte nach Gruppe (Ausgabe in Arbeitsblatt "Stack Replicates“ - Replikationen stapeln) und berechnen Sie dann jede Gruppe als eine Stichprobe.

Lesen Sie auf dieser Seite die Informationen zu allen Bedienelementen der Statistik für gesamtes Blatt.

t-Test bei einer Stichprobe

  1. Wählen Sie im Menü Statistik: Hypothesentests: t-Test bei einer Stichprobe.
  2. Wählen Sie die Eingabedatenanordnung im geöffneten Dialog:
    Replikationen vor Analyse mitteln Die Werte in jeder Zeile werden gemittelt. Dann wird die Analyse auf die gemittelten Werte durchgeführt.
    Jede Teilspalte separat analysieren Die Analyse wird unabhängig für jede Teilspalte durchgeführt.
    Teilspalten vor Analyse zusammenfassen Alle Teilspaltenwerte stapeln und sie dann als eine Stichprobe analysieren

Lesen Sie auf dieser Seite die Informationen zu allen Bedienelementen des t-Test bei einer Stichprobe.

Zweifache ANOVA

  1. Wählen Sie im Menü Statistik: ANOVA: Zweifache ANOVA.
  2. Vergeben Sie im aufgerufenen Dialog den zeilenweisen und spaltenweisen Faktoren jeweils einen Namen.

Lesen Sie auf dieser Seite die Informationen zu allen Bedienelementen der zweifachen ANOVA.

Zweifache ANOVA mit wiederholten Messungen

  1. Wählen Sie im Menü Statistik: ANOVA: Zweifache ANOVA bei wiederholten Messungen.
  2. Im geöffneten Dialog:
    Subjekte definieren Legen Sie fest, wie Subjekte definiert werden. Die Anzahl der Subjekte wird zur Bestätigung in Klammern angezeigt.
    Faktornamen Vergeben Sie den zeilenweisen und spaltenweisen Faktoren jeweils einen Namen.

Lesen Sie auf dieser Seite die Informationen zu allen Bedienelementen der zweifachen ANOVA bei wiederholten Messungen.

Dreifache ANOVA

  1. Wählen Sie im Menü Statistik: ANOVA: Dreifache ANOVA.
  2. Vergeben Sie im geöffneten Dialog jeweils einen Namen für die drei Faktoren.

Lesen Sie auf dieser Seite die Informationen zu allen Bedienelementen der dreifachen ANOVA.
