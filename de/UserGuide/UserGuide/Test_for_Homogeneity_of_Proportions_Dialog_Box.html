Eingabe

Test auf Homogenität der Anteile unterstützt mit Zusammengefasst und Roh zwei Eingabedatenformen.

Zusammengefasst Führen Sie den Test mit Hilfe einer zusammenfassenden Statistik durch, die Sie manuell in den Dialog eingeben.
  • Stichprobenname
Legen Sie den Namen der Stichprobe fest. Sie können eine Spalte als Sticprobenname festlegen oder durch Leerzeichen getrennte Zeichenketten eingeben.
  • Stichprobenumfang
Die Gesamtanzahl der Beobachtungen Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Werte. (Mindestens 3 Stichproben.)
  • Anzahl der Ereignisse
Legen Sie den Wert für die Anzahl der Ereignisse fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Werte. (Mindestens 3 Stichproben.)
Roh Führen Sie den Test anhand eines Datensatzes in einer Spalte durch.
  • Stichprobe
Legen Sie Spalten als den Stichprobendatensatz fest. (Mindestens 3 Spalten.)
  • Ereignis
Legen Sie die Anzahl der Ereignisse fest.

Statistik

Kontingenztabelle Dieser Zweig bestimmt, welche Statistiken in der Kontigenztabelle berechnet und ausgegeben werden.
  • Anzahl
Die beobachtete Häufigkeit für jede Zelle
  • Erwartete Anzahlen
Die beobachtete Häufigkeit für jede Zelle unter der Annahme, dass die Spalten- und Zeilenvariable unabhängig sind
  • Residuen
Die Differenz zwischen dem beobachteten Wert und dem erwarteten Wert.
  • Standardisierte Residuen
Auch als Residuum nach Pearson bezeichnet. Die Option standardisiert Residuen, indem sie durch die Quadratwurzel der erwarteten Anzahl geteilt werden.
  • Korrigierte Residuen
Es wird weiter standardisiert, indem der Gesamtumfang der Stichprobe berücksichtigt wird. Es ist das nützlichste Residuum zum Vergleichen von Residuen zwischen verschiedenen Zellen.
Effektgröße
  • Cramérs V
Eine Statistik, die das Chi-Quadrat korrigiert, sowohl mit dem Stichprobenumfang als auch mit der Dimension der Tabelle (n*m). Sie wird gemeinhin verwendet, um die Assoziation zwischen Tabellen, die verschiedene Dimensionen haben, zu vergleichen.

Paarweiser Vergleich

Bonferroni Die Bonferroni-Method prüft den gesamten Fehler 1. Art und ist konservativer als Tukey. Die Methode wird im Allgemeinen für alle paarweisen Vergleichstests verwendet.
Dunn-Sidak Dies ist eine leistungsstärkere Methode als der Dunnett-Test, insbesondere wenn die Anzahl der Vergleich hoch ist.
Dunnett Dunnett ist ein leistungsstarker Test, um Behandlungen mit einem Kontrollwert zu vergleichen. Mit ihm ist es besser möglich, wirkliche Differenzen zu erkennen.
Holm-Bonferroni Diese Methode ist weniger konservativ und dafür leistungsstärker als die Bonferroni-Methode. Dadurch wird die Chance größer, Nullhypothesen mit der Bonferroni-Holm-Methode zurückzuweisen.
Holm-Sidak Die Methode ist leistungsstärker als der Holm-Test. Sie kann jedoch nicht dazu verwendet werden, eine Reihe von Konfidenzintervallen zu berechnen.
Tabelle der Gruppenbuchstaben Die Differenz des Mittelwerts wird mit Buchstaben gezeigt. Der gleiche Buchstabe bedeutet, dass keine signifikante Differenz besteht. Ein unterschiedlicher Buchstabe bedeutet, dass es eine signifikante Differenz zwischen den zwei Gruppen gibt.

Analyse der Trennschärfe

Relevante Mindestdifferenz aufheben

Differenz(en) für festgelegte Trennschärfe Wenn die Relevante Mindestdifferenz nicht festgelegt ist, ist diese Option verfügbar.

Die Differenzen für die festlegten Trennschärfen werden ausgegeben. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve.

Trennschärfe(n) Wenn die Option Differenz(en) für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Trennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.

Relevante Mindestdifferenz festlegen

Relevante Mindestdifferenz (MDI) Legen Sie die Mindestdifferenz fest, für die Sie sich interessieren. Sobald Sie einen Wert in dieses Feld eingeben, zeigt das Diagramm der Trennschärfeanalyse den Mindeststichprobenumfang, um diese Differenz in verschiedenen Trennschärfen zu entdecken.
Stichprobenumfang/-umfänge für festgelegte Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Geben Sie die Stichprobenumfänge für die festlegten Trennschärfen aus. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve. Wenn die Option aktiviert ist, wird der Standardwert der Trennschärfe verwendet.

Trennschärfe(n) Wenn die Option Stichprobenumfang/-umfänge für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Zieltrennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.
Trennschärfe basierend auf Testdaten Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe eines Tests (die Wahrscheinlichkeit, die Nullhypothese abzulehnen, wenn sie falsch ist).

Hypothetische Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe des Tests für verschiedene Stichprobenumfänge. Wenn diese Option aktiviert ist, wird die entsprechende Kurve zur Trennschärfekurve hinzugefügt.

Hypothetische/r Stichprobenumfang/-umfänge Wenn Relevante Mindestdifferenz und Hypothetische Trennschärfe aktiviert ist, wird diese Option verfügbar.

Legen Sie den/die hypothetischen Stichprobenumfang/-umfänge für die Berechnung der Trennschärfe fest.

Ausgabe

Grafischer Zusammenfassungsbericht Legen Sie fest, ob der grafische Zusammenfassungsbericht angezeigt werden soll.
Grafischer Bericht der Trennschärfeanalyse Legen Sie fest, ob der grafische Bericht der Trennschärfeanalyse angezeigt werden soll. Die Trennschärfekurve zeigt, wie die statistische Trennschärfe des Tests sich ändert, wenn die Differenz zwischen den Anteilen wechselt. Die Trennschärfe ist die Wahrscheinlichkeit, dass die Nullhypothese verworfen wird, wenn die wahre Differenz sich von 0 unterscheidet.
Zeichnungsdaten Legen Sie das Arbeitsblatt für die Ausgabe der Zeichnungsdatensätze fest.
Ergebnis Legen Sie das Ausgabearbeitsblatt für die Testergebnisse fest.
