Eingabe

Der Test auf Varianzen bei einer Stichprobe unterstützt mit Roh, Zusammengefasste Daten (StdAbw.) und Zusammengefasste Daten (Varianz) drei Eingabedatenformen.

Roh Geben Sie die Spalte mit Bereichsformat ein.

Hilfe zum Festlegen von Bereichen finden Sie hier: Eingabedaten festlegen

Zusammengefasste Daten (StdAbw.) Zusammengefasste Daten sind Standardabweichung und Stichprobenumfang, vorbereitet für Stichproben.

Geben Sie die folgenden Zusammengefassten Daten durch Auswahl von Spalten aus dem Arbeitsblatt oder manuelle Eingabe im Dialog ein.

  • Stichprobenname
Legen Sie den Namen der Stichprobe fest. Sie können eine Spalte als Stichprobenname festlegen oder durch Leerzeichen getrennte Zeichenketten eingeben oder sie leer lassen.
  • StdAbw.
Legen Sie die Standardabweichung der Daten fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Zahlen eingeben. (Die StdAbw. sollte größer als 0 sein.)
  • Stichprobenumfang
Legen Sie die Gesamtanzahl der Daten fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Zahlen eingeben. (Der Stichprobenumfang sollte größer als 0 sein.)
Zusammengefasste Daten (Varianz) Zusammengefassten Daten ist Varianz und Stichprobenumfang, vorbereitet für Stichproben.

Geben Sie die folgenden Zusammengefassten Daten durch Auswahl von Spalten aus dem Arbeitsblatt oder manuelle Eingabe im Dialog ein.

  • Stichprobenname
Legen Sie den Namen der Stichprobe fest. Sie können eine Spalte als Stichprobenname festlegen oder durch Leerzeichen getrennte Zeichenketten eingeben oder sie leer lassen.
  • Varianz
Legen Sie die Varianz der Daten fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Zahlen eingeben.
  • Stichprobenumfang
Legen Sie die Gesamtanzahl der Daten fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Zahlen eingeben. (Der Stichprobenumfang sollte größer als 0 sein.)

Test

Testen auf Optionen:
  • Varianz
  • Standardabweichung (Standardoption)
Testvarianz Falls Varianz in der Auswahlliste Testen auf ausgewählt ist, können Sie die zu testende hypothetische Varianz festlegen.
Test-StdAbw. Falls Standardabweichung in der Auswahlliste Testen auf ausgewählt ist, können Sie die zu testende Standardabweichung festlegen.
Nullhypothese Die zu testende Nullhypothese (d.h. Stichprobenvarianz = Testvarianz).
Alternativhypothese Optionen:
Varianz <> Testvarianz oder StdAbw. <> Test-StdAbw.
Die Stichprobenvarianz/-standardabweichung unterscheidet sich von der hypothetischen Varianz/Standardabweichung.
Varianz > Testvarianz oder StdAbw. > Test-StdAbw.
Die Stichprobenvarianz/-standardabweichung ist größer als die hypothetische Varianz/Standardabweichung (einseitiger Test nach oben).
Varianz < Testvarianz oder StdAbw. < Test-StdAbw.
Die Stichprobenvarianz/-standardabweichung ist kleiner als die hypothetische Varianz/Standardabweichung (einseitiger Test nach unten).
Signifikanzniveau Das Signifikanzniveau des Tests
Kondenzintervall(e) Legen Sie fest, ob die Konfidenzintervalle für den Mittelwert berechnet werden.
Konfidenzniveau(s) in % Legen Sie die Konfidenzniveaus (durch Komma getrennt) fest (%). Diese Option ist nur verfügbar, wenn Konfidenzintervall(e) aktiviert ist.
Testmethode Wählen Sie die Testmethode aus.
  • Chi-Quadrat
Ist nur für die Normalverteilung. Gibt das Ergebnis des Chi-Quadrat-Tests mit Chi-Quadrat, Freiheitsgraden und Wahrsch.>Chi-Quadrat und den Konfidenzintervallen für Varianz/Standardabweichung aus.
  • Bonett
Für jegliche stetige Verteilungen. Gibt das Ergebnis des Bonett-Tests mit p-Wert und den Konfidenzintervallen für Varianz/Standardabweichung aus.
Wenn die Eingabedatenform Zusammengefasste Daten (StdAbw.)/(Varianz) ist, wird die Bonett-Option deaktiviert.

Trennschärfeanalyse

Relevante Mindestdifferenz aufheben

Differenz(en) für festgelegte Trennschärfe Wenn die Relevante Mindestdifferenz nicht festgelegt ist, ist diese Option verfügbar.

Die Differenzen für die festlegten Trennschärfen werden ausgegeben. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve.

Trennschärfe(n) Wenn die Option Differenz(en) für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Trennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.

Relevante Mindestdifferenz festlegen

Relevante Mindestdifferenz Legen Sie die Mindestdifferenz von der Testvarianz/-standardabweichung und der Zielvarianz/-standardabweichung fest. Sobald Sie einen Wert in dieses Feld eingeben, zeigt das Diagramm der Trennschärfeanalyse den Mindeststichprobenumfang, um diese Differenz in verschiedenen Trennschärfen zu entdecken.
Stichprobenumfang/-umfänge für festgelegte Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Geben Sie die Stichprobenumfänge für die festlegten Trennschärfen aus. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve. Wenn die Option aktiviert ist, wird der Standardwert der Trennschärfe verwendet.

Trennschärfe(n) Wenn die Option Stichprobenumfang/-umfänge für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Zieltrennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.
Trennschärfe basierend auf Testdaten Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe für den Stichprobenumfang der Testdaten. (Wahrscheinlichkeit, die Nullhypothese zurückzuweisen, wenn diese falsch ist)

Hypothetische Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe des Tests für verschiedene Stichprobenumfänge. Wenn diese Option aktiviert ist, wird die entsprechende Kurve zur Trennschärfekurve hinzugefügt.

Hypothetische/r Stichprobenumfang/-umfänge Wenn Relevante Mindestdifferenz und Hypothetische Trennschärfe aktiviert ist, wird diese Option verfügbar.

Legen Sie den/die hypothetischen Stichprobenumfang/-umfänge für die Berechnung der Trennschärfe fest.

Diagramme

Histogramm Zeichnen Sie ein Histogramm der Stichprobendaten.
Boxdiagramm Zeichnen ein Boxdiagramm der Stichprobendaten.

Hinweis: Wenn in den Datensätzen Ausreißer erkannt werden, wird eine Fußnote unter dem Boxdiagramm gezeigt, um Sie darauf hinzuweisen, sie zu untersuchen. Wenn Sie die Ausreißer ausschließen möchten, können Sie auf die dreieckige Schaltfläche am Ende der Fußnote klicken, um Ausreißer zu markieren und neu zu berechnen.

Diagramme des gleichen Typs in einem Graph anordnen Ordnen Sie die Diagramme des gleichen Typs in einer Grafik an. Beachten Sie, dass bei Histogrammen die Layer vertikal angeordnet werden; bei Boxdiagrammen werden sie horizontal angeordnet.
Hinweis: Wenn die Eingabedatenform Zusammengefasste Daten (StdAbw.)/(Varianz) ist, werden die obigen Zeichnungen nicht ausgegeben.

Ausgabe

Ausgabe Ergebnisprotokoll

Legen Sie die Ergebnisse fest, die im Ergebnisfenster ausgegeben werden.

Grafischer Zusammenfassungsbericht Erstellen Sie einen Zusammenfassungsbericht, einschließlich Balken für den p-Wert und die Effektgröße sowie ein Datenverteilungsdiagramm. Es werden auch die Ergebnistabellen an das Diagramm angehängt, um die statistischen Werte zu zeigen.

Die Fußnote nach dem Zusammenfassungsdiagramm diagnostiziert diese statistischen Ergebnisse.

Grafischer Bericht der Trennschärfeanalyse Legen Sie fest, ob der grafische Bericht der Trennschärfeanalyse angezeigt werden soll. Die Trennschärfekurve zeigt, wie die statistische Trennschärfe des Tests sich ändert, wenn die Differenz zwischen den Anteilen wechselt. Die Trennschärfe ist die Wahrscheinlichkeit, dass die Nullhypothese verworfen wird, wenn die wahre Differenz sich von 0 unterscheidet.

Es wird eine Fußnote nach dem Trennschärfekurvendiagramm hinzugefügt, um die Diagnoseergebnisse der Trennschärfeanalyse zu zeigen. Eine Trennschärfe von 80 % wird gemeinhin als ausreichend betrachtet.

Zeichnungsdaten ausgeben Legen Sie ein Arbeitsblatt für die Ausgabe der gezeichneten Daten fest (Origin erzeugt beim Erstellen von Zeichnungen tabellarische Daten).
Ergebnisse ausgeben Legen Sie das Ausgabearbeitsblatt für die Testergebnisse fest.
Hinweis:
  • Wenn die Eingabedatenform Zusammengefasste Daten (StdAbw.)/(Varianz) ist, wird der grafische Zusammenfassungsbericht nicht ausgegeben.
  • Wenn mehrere Daten eingegeben werden (sowohl Roh als auch Zusammengefassten Daten), wird der grafische Bericht der Trennschärfeanalyse nicht ausgegeben.
  • Wenn die Eingabedatenform Roh ist, wird die Tabelle Maskierte Daten und Schlechte Daten (fehlender Wert) im Berichtsblatt angezeigt.
