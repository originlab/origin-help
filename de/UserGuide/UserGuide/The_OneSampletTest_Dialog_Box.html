Eingabe

Der t-Test bei einer Stichprobe unterstützt mit Roh und Zusammengefasste Daten zwei Eingabedatenformen.

Roh Führen Sie den Test mit Hilfe einer Spalte/von Spalten mit Bereichsformat durch. Jede Spalte enthält Antwortdaten von einer Stufe der Faktorvariablen.

Hilfe zum Festlegen von Bereichen finden Sie hier: Eingabedaten festlegen

Zusammengefasste Daten Zusammengefasste Daten sind Mittelwert, Standardabweichung und Stichprobenumfang, vorbereitet für Stichproben. Die Option unterstützt mehrere Zusammengefasste Daten.

Geben Sie die folgenden Zusammengefassten Daten durch Auswahl von Spalten aus dem Arbeitsblatt oder manuelle Eingabe im Dialog ein.

  • Stichprobenname
Legen Sie den Namen der Stichprobe fest. Sie können eine Spalte als Stichprobenname festlegen oder durch Leerzeichen getrennte Zeichenketten eingeben oder sie leer lassen.
  • Mittelwert
Legen Sie den Mittelwert der Daten fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Zahlen eingeben.
  • StdAbw.
Legen Sie die Standardabweichung der Daten fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Zahlen eingeben. (Die StdAbw. sollte größer als 0 sein.)
  • Stichprobenumfang
Legen Sie die Gesamtanzahl der Daten fest. Sie können einen Spaltendatensatz festlegen oder durch Leerzeichen getrennte Zahlen eingeben. (Der Stichprobenumfang sollte größer als 0 sein.)

t-Test für Mittelwert

Testmittelwert Der zu testende hypothetische Mittelwert Wenn Sie einen Wert eingeben, werden die Null- und Alternativhypothese entsprechend angepasst.
Nullhypothese Die zu testende Nullhypothese

(Mittelwert = Testmittelwert)

Alternativhypothese Die Alternativhypothese

Optionen:

Mittelwert <>Testmittelwert

Wird für beidseitigen Test verwendet. Diese Option testet, ob der Stichprobenmittelwert sich von dem hypothetischen Mittelwert unterscheidet.

Mittelwert >Testmittelwert

Wird für den einseitigen Test nach oben verwendet. Diese Option testet, ob der Stichprobenmittelwert größer ist als der hypothetische Mittelwert.

Mittelwert < Testmittelwert

Wird für den einseitigen Test nach unten verwendet. Diese Option testet, ob der Stichprobenmittelwert kleiner ist als der hypothetische Mittelwert.
Signifikanzniveau Legen Sie das Signifikanzniveau fest.
Effektgröße Berechnen Sie den Wert von Cohens d, um die Effektgröße zu zeigen, die der Differenzbetrag zwischen dem tatsächlichen Mittelwert und dem Testmittelwert ist.
Kondenzintervall(e) Legen Sie fest, ob das/die Konfidenzintervall(e) für den Mittelwert berechnet wird/werden.

Berechnungseinzelheiten finden Sie unter Algorithmen (t-Test bei einer Stichprobe).

Konfidenzniveau(s) in % Legen Sie mit Leerzeichen getrennte Konfidenzniveaus fest, (1-)%. Diese Option ist verfügbar, wenn Konfidenzintervall(e) aktiviert wird.

Trennschärfeanalyse

Relevante Mindestdifferenz aufheben

Differenz(en) für festgelegte Trennschärfe Wenn die Relevante Mindestdifferenz nicht festgelegt ist, ist diese Option verfügbar.

Die Differenzen für die festlegten Trennschärfen werden ausgegeben. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve.

Trennschärfe(n) Wenn die Option Differenz(en) für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Trennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.

Relevante Mindestdifferenz festlegen

Relevante Mindestdifferenz (MDI) Legen Sie die Mindestdifferenz vom Testmittelwert fest, an dem Sie interessiert sind. Sobald Sie einen Wert in dieses Feld eingeben, zeigt das Diagramm der Trennschärfeanalyse den Mindeststichprobenumfang, um diese Differenz in verschiedenen Trennschärfen zu entdecken.
Stichprobenumfang/-umfänge für festgelegte Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Geben Sie die Stichprobenumfänge für die festlegten Trennschärfen aus. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve.

Trennschärfe(n) Wenn die Option Stichprobenumfang/-umfänge für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Zieltrennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.
Trennschärfe basierend auf Testdaten Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe für den Stichprobenumfang der Testdaten. (Wahrscheinlichkeit, die Nullhypothese zurückzuweisen, wenn diese falsch ist)

Hypothetische Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe des Tests für verschiedene Stichprobenumfänge. Wenn diese Option aktiviert ist, können Sie hypothetische Stichprobenumfang/Stichprobenumfänge im Feld unten festlegen. Sie wird eine entsprechende Kurve zur Trennschärfekurve hinzufügen.

Hypothetische/r Stichprobenumfang/-umfänge Wenn Relevante Mindestdifferenz und Hypothetische Trennschärfe aktiviert ist, wird diese Option verfügbar.

Legen Sie den/die hypothetischen Stichprobenumfang/-umfänge für die Berechnung der Trennschärfe fest.

Hinweis: Wenn mehrere Daten eingegeben werden (sowohl Roh als auch Zusammengefasste Daten), wird der Bericht der Trennschärfe nicht ausgegeben.

Ausgabe

Hilfe zum Festlegen der Bereiche finden Sie unter: Ergebnisse ausgeben

Ausgabe Ergebnisprotokoll

Legen Sie die Ergebnisse fest, die im Ergebnisfenster ausgegeben werden.

Grafischer Zusammenfassungsbericht Erstellen Sie einen Zusammenfassungsbericht, einschließlich Balken für den p-Wert und die Effektgröße sowie ein Datenverteilungsdiagramm. Es werden auch die Ergebnistabellen an das Diagramm angehängt, um die statistischen Werte zu zeigen.

Die Fußnote nach dem Zusammenfassungsdiagramm diagnostiziert diese statistischen Ergebnisse.

Grafischer Bericht der Trennschärfeanalyse Erstellen Sie einen grafischen Bericht der Trennschärfeanalyse mit Trennschärfekurven. Die Ausgabetabelle und Trennschärfekurven entsprechen der Einstellung auf der Registerkarte Trennschärfeanalyse.
  • Wenn im Bearbeitungsfeld Relevante Mindestdifferenz kein Wert eingegeben wurde, wird nur die Trennschärfekurve des aktuellen Stichprobenumfangs ausgegeben. Die Trennschärfe bei 60 %, 70 %, 80 % und 90 % (Standardwert) wird gekennzeichnet, um die Differenz bei diesen Trennschärfewerten zu zeigen.
  • Wenn ein Differenzwert im Bearbeitungsfeld Relevante Mindestdifferenz festgelegt wurde, werden die Trennschärfekurven ausgegeben: Die Trennschärfekurven bei 60 %, 70 %, 80 % und 90 % und dem aktuellen Stichprobenumfang. Der Stichprobenumfang, mit dem die Mindestdifferenz entdeckt wird, ist dann aufgeführt.

Es wird eine Fußnote nach dem Trennschärfekurvendiagramm hinzugefügt, um die Diagnoseergebnisse der Trennschärfeanalyse zu zeigen. Eine Trennschärfe von 80 % wird gemeinhin als ausreichend betrachtet.

Zeichnungsdaten ausgeben Legen Sie ein Arbeitsblatt für die Ausgabe der gezeichneten Daten fest (Origin erzeugt beim Erstellen von Zeichnungen tabellarische Daten).

Dieses Element ist nur verfügbar, wenn das Eingabedatenformat "Roh" ist.

Ergebnisse ausgeben Legen Sie das Ausgabearbeitsblatt für die Testergebnisse fest.
Hinweis:
  • Wenn die Eingabedatenform Zusammengefassten Daten ist, wird der grafischer Zusammenfassungsbericht nicht ausgegeben.
  • Wenn mehrere Daten eingegeben werden (sowohl Roh als auch Zusammengefassten Daten), wird der grafische Bericht der Trennschärfeanalyse nicht ausgegeben.
  • Wenn die Eingabedatenform Roh ist, wird die Tabelle Maskierte Daten und Schlechte Daten (fehlender Wert) im Berichtsblatt angezeigt.
