Eingabe

Der Test von Anteilen bei einer Stichprobe unterstützt mit Roh und Zusammengefassten Daten zwei Eingabedatenformen.

Zusammengefasst Führen Sie den Test mit Hilfe einer zusammenfassenden Statistik durch, die Sie manuell in den Dialog eingeben.
  • Anzahl der Ereignisse

Test von Anteilen

Testanteil Der zu testende hypothetische Anteil
Nullhypothese Die zu testende Nullhypothese (Stichprobenanteil = Testanteil).
Alternativhypothese Optionen:
  • Proportion <> Testanteil
Ein beidseitiger Test von Anteilen, der zu beantworten versucht, ob der Anteil der Stichprobe = Testanteil.
  • Proportion > Testanteil
Ein einseitiger Test von Anteilen nach oben, der zu beantworten versucht, ob der Anteil der Stichprobe größer ist als der Testanteil.
  • Proportion < Testanteil
Ein einseitiger Test von Anteilen nach unten, der zu beantworten versucht, ob der Anteil der Stichprobe kleiner ist als der hypothetische Anteil.
Signifikanzniveau Das Signifikanzniveau des Tests
Kondenzintervall(e) Berechnen Sie das Konfidenzintervall für den wahren (Grundgesamtheit) Anteil.
Konfidenzniveau(s) in % Legen Sie die Konfidenzniveaus fest, für die die Konfidenzintervalle berechnet werden. Diese Option ist nur verfügbar, wenn Konfidenzintervall(e) aktiviert ist.
Testmethode Origin verwendet zwei Methoden zum Berechnen von p-Werten und Konfidenzintervallen für Tests von Anteilen bei einer Stichprobe (Dokumentation zur Approximation der Normalverteilung und zum Binomialtest finden Sie auf der Seite zum Algorithmus):
  • Approximation der Normalverteilung
Die Approximation der Normalverteilung wird immer berechnet. Im Allgemeinen erhalten Sie ein befriedigendes Ergebnis, wenn Erfolge ≥ 10 und wenn Stichprobenumfang - Erfolge ≥ 10. Die Qualität der Approximation neigt dazu, sich mit zunehmendem Stichprobenumfang zu verbessern.
Bei kleinen Stichprobenumfängen oder extremen zugrunde liegenden Anteilen ( nahe 0 oder 1) verschlechtert sich die Normal-Approximation.
  • Binomialer exakter Test
Der Binomialtest verwendet direkt die Wahrscheinlichkeitsfunktion der binomialen Verteilung, wobei er nach der oberen und unteren Grenze auflöst, indem er die Wahrscheinlichkeit der Enden separat auf setzt.
Diese Methode verwendet eine ultrakonservative Strategie. Sie erzeugt übermäßig breite Kondenzintervalle und eine niedrige statistische Trennschärfe für Hypothesentests. Sie ist außerdem geeignet für Daten mit kleinem Stichprobenumfang.
  • Angepasster exakter Blaker-Test
Blakers exakter Test betrachtet beide Enden gemeinsam und reduziert dabei signifikant die unnötige Intervallbreite. Die angepasste Version optimiert die Algorithmen weitergehend und löst dabei Probleme der numerischen Grenzen und stellt die strenge Übereinstimmung zwischen p-Werten und Konfidenzintervallen sicher.
Verglichen mit der Normal-Approximation und dem exakten Binomialtest kombiniert der angepasste exakte Blaker-Test Exaktheit mit Prägnanz: Er bleibt es streng exakte Methode (tatsächliche Abdeckungsrate ), ergibt jedoch engere Konfidenzintervalle und eine höhere statistische Trennschärfe als der exakte Binomialtest.

Trennschärfeanalyse

Relevante Mindestdifferenz aufheben

Differenz(en) für festgelegte Trennschärfe Wenn die Relevante Mindestdifferenz nicht festgelegt ist, ist diese Option verfügbar.

Die Differenzen für die festlegten Trennschärfen werden ausgegeben. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve.

Trennschärfe(n) Wenn die Option Differenz(en) für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Trennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.

Relevante Mindestdifferenz festlegen

Relevante Mindestdifferenz (MDI) Legen Sie die Mindestdifferenz fest, für die Sie sich interessieren. Sobald Sie einen Wert in dieses Feld eingeben, zeigt das Diagramm der Trennschärfeanalyse den Mindeststichprobenumfang, um diese Differenz in verschiedenen Trennschärfen zu entdecken.
Hinweis:

Bei einem Test von Anteilen bei einer Stichprobe gibt es eine Beschränkung für die Einstellung der relvanten Mindestdifferenz (MDI). Das ist verbunden mit dem Testanteil, der auf der Registerkarte Test von Anteilen festgelegt ist.

  • Wen Anteil <> Testanteil, sollte der MDI-Wert ein positiver Wert kleiner als der maximale Wert zwischen Testanteil und 1-Testanteil sein.
  • Wenn Anteil > Testanteil, sollte der MDI-Wert ein positiver Wert kleiner als der 1-Testanteil sein.
  • Wenn Anteil < Testanteil, sollte der MDI-Wert ein positiver Wert kleiner als der Testanteil sein.
Stichprobenumfang/-umfänge für festgelegte Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Geben Sie die Stichprobenumfänge für die festlegten Trennschärfen aus. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve. Wenn die Option aktiviert ist, wird der Standardwert der Trennschärfe verwendet.

Trennschärfe(n) Wenn die Option Stichprobenumfang/-umfänge für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Zieltrennschärfewerte, getrennt durch ein Leerzeichen, eingeben. Standardtrennschärfewerte sind 60 %, 70 %, 80 % und 90 %.
Trennschärfe basierend auf Testdaten Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe für den Stichprobenumfang der Testdaten. (Wahrscheinlichkeit, die Nullhypothese zurückzuweisen, wenn diese falsch ist)

Hypothetische Trennschärfe Wenn die Option Relevante Mindestdifferenz festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe des Tests für verschiedene Stichprobenumfänge. Wenn diese Option aktiviert ist, wird die entsprechende Kurve zur Trennschärfekurve hinzugefügt.

Hypothetische/r Stichprobenumfang/-umfänge Wenn Relevante Mindestdifferenz und Hypothetische Trennschärfe aktiviert ist, wird diese Option verfügbar.

Legen Sie den/die hypothetischen Stichprobenumfang/-umfänge für die Berechnung der Trennschärfe fest.

Ausgabe

Hilfe zum Festlegen der Bereiche finden Sie unter: Ergebnisse ausgeben

Ausgabe Ergebnisprotokoll Legen Sie die Ergebnisse fest, die im Ergebnisfenster ausgegeben werden.
Grafischer Zusammenfassungsbericht Legen Sie fest, ob der grafische Zusammenfassungsbericht angezeigt werden soll.
Grafischer Bericht der Trennschärfeanalyse Legen Sie fest, ob der grafische Bericht der Trennschärfeanalyse angezeigt werden soll. Die Trennschärfekurve zeigt, wie die statistische Trennschärfe des Tests sich ändert, wenn die Differenz zwischen den Anteilen wechselt. Die Trennschärfe ist die Wahrscheinlichkeit, dass die Nullhypothese verworfen wird, wenn die wahre Differenz sich von 0 unterscheidet.

Es wird eine Fußnote nach dem Trennschärfekurvendiagramm hinzugefügt, um die Diagnoseergebnisse der Trennschärfeanalyse zu zeigen.

Ergebnisse ausgeben Legen Sie das Ausgabearbeitsblatt für die Testergebnisse fest.
Zeichnungsdaten ausgeben Legen Sie das Arbeitsblatt für die Ausgabe der Zeichnungsdatensätze fest.
Hinweis:
  • Wenn die Eingabedatenform Roh ist, wird die Tabelle Maskierte Daten und Schlechte Daten (fehlender Wert) im Berichtsblatt angezeigt.
