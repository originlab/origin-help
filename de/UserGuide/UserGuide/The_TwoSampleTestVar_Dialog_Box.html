Die Stichprobendatenspalte

Test

Testen auf Optionen:
  • Varianzverhältnis
  • Standardabweichungsverhältnis (Standardoption)
Testverhältnis Legen Sie das zu testende hypothetische Verhältnis fest.
Nullhypothese Die zu testende Nullhypothese (d. h. Varianz1 = Varianz2).
Alternativhypothese Optionen:
  • Varianz 1/Varianz 2 <> Testverhältnis oder StdAbw. 1/StdAbw. 2 <> Testverhältnis
Testen Sie, ob die zwei Varianzen/StdAbw. gleich sind.
  • Varianz 1/Varianz 2 > Testverhältnis oder StdAbw. 1/StdAbw. 2 > Testverhältnis
Testen Sie, ob die Varianz/StdAbw. von Stichprobe 1 größer ist als die Varianz/StdAbw. von Stichprobe 2.
  • Varianz 1/Varianz 2 < Testverhältnis oder StdAbw. 1/StdAbw. 2 < Testverhältnis
Testen Sie, ob die Varianz/StdAbw. von Stichprobe 1 kleiner ist als die Varianz/StdAbw. von Stichprobe 2.
Signifikanzniveau Legt das Signifikanzniveau fest.
Kondenzintervall(e) Berechnet die Konfidenzintervalle für die Differenzen der Mittelwerte.
Konfidenzniveau(s) in % Legt die mit Leerzeichen getrennten Konfidenzniveaus fest. Diese Option ist nur verfügbar, wenn Konfidenzintervall(e) aktiviert ist.
Testmethode Wählen Sie die Testmethode aus:
  • F-Test
Berechnet das direkte Verhäktnis der zwei Stichprobenvarianzen. Extrem empfindlich auf Abweichungen von der Normalverteilung. Sogar leichte Nicht-Normalverteilung verursacht überhöhte Fehlerraten vom Typ I. Wenn die Daten konform sind mit der Normalverteilung, dann ist der F-Test typischerweise leistungsstärker als andere Methoden.
  • Bonett
Für jegliche stetige Verteilungen. Gibt das Ergebnis des Bonett-Tests mit p-Wert und den Konfidenzintervallen für Varianz/Standardabweichung aus. Sehr widerstandsfähig gegenüber moderater Nicht-Normalverteilung und behält höhere statistische Trennschärfe bei. Kann für stetige Verteilungen mit Stichprobenumfängen von n > 20 pro Gruppe verwendet werden. (Für kleine Stichproben mit extremer Schiefe oder stark besetzten Enden.)
Wenn die Eingabedatenform Zusammengefasste Daten (StdAbw.)/(Varianz) ist, wird die Bonett-Option deaktiviert.


  • Brown-Forsythe
Eine Modifikation von Levenes Test. Berechnet die absoluten Abweichungen jeder Beobachtung von seinem Gruppenmedian und führt eine standardmäßige einfache ANOVA für diese transformierten Werte durch. Robustheit des Signifikanzniveaus gegenüber Verletzungen der angenommenen Normalverteilung. Kann bei sehr schiefen Daten, Verteilungen mit stark besetzten Enden oder Datensätzen, die bemerkenswerte Ausreißer enthalten, verwendet werden.
Wenn die Eingabedatenform Zusammengefasste Daten (StdAbw.)/(Varianz) ist, wird die Brown-Forsythe-Option deaktiviert.


Trennschärfeanalyse

Relevantes Verhältnis aufheben

Differenz(en) für festgelegte Trennschärfe Wenn das Relevante Verhältnis nicht festgelegt ist, ist diese Option verfügbar.

Die Differenzen für die festlegten Trennschärfen werden ausgegeben. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve. Wenn die Option aktiviert ist, wird der Standardwert der Trennschärfe verwendet.

Trennschärfe(n) Wenn die Option Differenz(en) für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Trennschärfewerte, getrennt durch ein Leerzeichen, eingeben.

Relevantes Verhältnis festlegen

Relevantes Verhältnis Legen Sie das Mindestverhältnis der Varianzen (oder Standardabweichungen) zwischen zwei unabhängigen Grundgesamtheiten fest.


Hinweis: Beim Festlegen des Relevanten Verhältnisses:

  • Falls Alternativhypothese <> Testverhältnis, sollte das Relevante Verhältnis ein positiver Wert und nicht 1 sein.
  • Falls Alternativhypothese >= Testverhältnis, sollte das Relevante Verhältnis > 1 sein.
  • Falls Alternativhypothese < Testverhältnis, sollte das Relevante Verhältnis < nicht 1 sein.
Stichprobenumfang/-umfänge für festgelegte Trennschärfe Wenn das Relevante Verhältnis festgelegt ist, wird diese Option verfügbar.

Geben Sie die Stichprobenumfänge für die festlegten Trennschärfen aus. Wenn diese Option ausgewählt ist, beeinflusst die festgelegte Trennschärfeeinstellung die Trennschärfe in der Trennschärfekurve. Wenn die Option aktiviert ist, wird der Standardwert der Trennschärfe verwendet.

Trennschärfe(n) Wenn die Option Stichprobenumfang/-umfänge für festgelegte Trennschärfe aktiviert ist, können Sie in dieses Bearbeitungsfeld die Zieltrennschärfewerte, getrennt durch ein Leerzeichen, eingeben.
Trennschärfe basierend auf Testdaten Wenn das Relevante Verhältnis festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe für den Stichprobenumfang der Testdaten. (Wahrscheinlichkeit, die Nullhypothese zurückzuweisen, wenn diese falsch ist)

Hypothetische Trennschärfe Wenn das Relevante Verhältnis festgelegt ist, wird diese Option verfügbar.

Berechnen Sie die Trennschärfe des Tests für verschiedene Stichprobenumfänge. Wenn diese Option aktiviert ist, wird die entsprechende Kurve zur Trennschärfekurve hinzugefügt.

Hypothetische/r Stichprobenumfang/-umfänge Wenn das Relevante Verhältnis und die Hypothetische Trennschärfe aktiviert ist, wird diese Option verfügbar.

Legen Sie den/die hypothetischen Stichprobenumfang/-umfänge für die Berechnung der Trennschärfe fest.
