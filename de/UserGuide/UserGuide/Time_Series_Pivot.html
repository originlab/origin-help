Pivot für Zeitreihen

Time-Series-Pivot

Origin unterstützt das Hilfsmittel Pivot für Zeitreihen, um eine Pivot-Tabelle zu erstellen und mit ihr die Datenzusammenfassung (der Statistik), basierend auf einer Datums-/Zeitspalte, zu visualisieren.

Um dieses Hilfsmittel zu öffnen, während eine Arbeitsmappe aktiviert ist,

  • wählen Sie Restrukturieren: Pivot für Zeitreihen ... im Menü.

Oder:

  • Führen Sie den Befehl wtspivot -d; im Skript- oder Befehlsfenster aus.

Dieses Hilfsmittel verwendet die X-Funktion Wtspivot.

Zeile

Aggregationsintervall Legen Sie das Aggregationsintervall der Zeit in den Zeilen der Pivot-Tabelle fest. Dieses Zeitintervall wird in der ersten Spalte der Pivot-Tabelle gezeigt.

Sie können diese Optionen in dieser Auswahlliste auswählen:

Zeitraum Legen Sie die Zeitgruppe des Aggregationsintervalls fest.

Entsprechend dem ausgewählten Aggregationsintervall können Sie den entsprechenden Zeitraum auswählen.

  • Wenn Jahr als Aggregationsintervall ausgewählt ist, können Sie 10 J.: Dekade als Zeitraum auswählen.
  • Wenn 3 Monate: Quartal, Monat, Woche oder Tag als Aggregationsintervall ausgewählt ist, können Sie Jahr als Zeitraum auswählen.
  • Wenn Woche oder Tag als Aggregationsintervall ausgewählt ist, können Sie Monat als Zeitraum auswählen.
  • Wenn Tag oder Stunde als Aggregationsintervall ausgewählt ist, können Sie Woche als Zeitraum auswählen.
  • Wenn 30 Min., 15 Min. oder Minute als Aggregationsintervall ausgewählt ist, können Sie Tag oder Stunde als Zeitraum auswählen.
Leere entfernen Aktivieren Sie dieses Kontrollkästchen, um die leeren Zeilen zu entfernen.
Anfang/Ende Geben Sie die Anfangs- und Endzeit der Zeilen der Pivot-Tabelle ein. Das Zeitformat des Anfangs und Endes basiert auf dem ausgewählten Aggregationsintervall. Sie können auf den blauen Hinweis verweisen, der oberhalb des Bearbeitungsfelds gezeigt wird. Wenn das Bearbeitungsfeld leer bleibt, ist die Anfang- oder Endzeit die Standardzeit der Tabelle.
Benutzerdefiniertes Format Sie können das Zeitformat, das in der ersten Spalte gezeigt wird, mit Ausnahme einiger Kombinationen von Aggregationsintervall und Zeitraum benutzerdefiniert anpassen.

Zum Beispiel: Wenn Aggregationsintervall = Monat und Zeitraum = Jahr, dann kann das Format nicht benutzerdefiniert angepasst werden.

Datums-/Zeitfenster

Legen Sie den Datums-/Zeitbereich fest, um den Quelldatumsbereich, der aggregiert war, zu steuern.

Aggregieren nach

Wählen Sie die Aggregationsmethode, um die Quelldaten auszuwählen, einschließlich

Benutzerdefiniert

Nur verfügbar, wenn Aggregieren nach auf Benutzerdefiniert gesetzt ist. Legen Sie die Zusammenfassungsmethode im Kombinationsfeld fest. Die dreieckige Schaltfläche neben dem Bearbeitungsfeld bietet einige häufig verwendete Statistikgrößen. Sie können sie mischen und Ihre eigene Zusammenfassungsmethode zusammenstellen. Sie können auch alle Methoden hinzufügen oder die Auswahl durch dieses Menü zurücksetzen.

Nullen zeigen, wenn leer

Legen Sie fest, ob die fehlenden Werte in der Pivot-Tabelle als Nullen angezeigt werden sollen.
