Function





Brief Description

Two sites competition function to describe the competition of a ligand for two types of receptors

Sample Curve

Parameter

Number: 8

Names: A1, A2, logKi_1, logKi_2, fraction, H1, H2_1, H2_2

Meanings: A1= top asymptote, A2=bottom asymptote, logKi_1=log10 high-affinity Ki, logKi_2=log10 low-affinity Ki, fraction=fraction of high-affinity sites, H1=hot ligand concentration, H2_1=hot ligand Kd for high-affinity site, H2_2=hot ligand Kd for low-affinity site

Lower Bounds: none

Upper Bounds: none

Derived Parameters

Ki_1=10^(logKi_1)

Ki_2=10^(logKi_2)

EC50_1=10^(logKi_1)*(1+H1/H2_1)

EC50_2=10^(logKi_2)*(1+H1/H2_2)

Script Access

nlf_TwoSiteCompFitKi(x,A1,A2,logKi_1,logKi_2,fraction,H1,H2_1,H2_2)
