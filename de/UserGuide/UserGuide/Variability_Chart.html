Datenanforderungen

Wählen Sie eine Y-Spalte mit mindestens einer Faktorspalte (bis zu 4 Faktoren).

Diagramm erstellen

Eine Streuungskarte erstellen:

  1. Markieren Sie mindestens eine Arbeitsblattspalte aus (oder einen Bereich aus einer Spalte).
  2. Wählen Sie Zeichnen > Statistisch: Streuungskarte, um den Dialog plot_vari zu öffnen.

Der Dialog plot_vari

Registerkarte Eingabe

Daten Wählen Sie die Spalte(n) mit den zu zeichnenden Quelldaten.
Faktoren Wählen Sie die Spalten als Faktoren. Diese Spalten werden als Gruppierungsinformationen behandelt. Falls mehrere Spalten ausgewö´ählt worden sind, wird die Gruppierung verschachtelt.

Registerkarte Eigenschaften

Mittelwert der Zelle verbinden Legen Sie fest, ob die Mittelwerte des letzten Faktors verbunden werden sollen.
Mittelwertlinien für Faktoren zeigen Legen Sie fest, ob die Mittelwertlinien für Faktoren gezeigt werden sollen.

Die Faktoren, die hier aufgelistet sind, werden genauso organisiert wie die Faktoren, die Sie auf der Registerkarte Eingabe eingegeben haben. Sie können den/die Faktor/en wählen, die Sie als Mittelwertlinien zeigen möchten.

Gesamtmittelwertlinie zeigen Legen Sie fest, ob die Linie des Gesamtmittelwerts in der Karte gezeigt werden soll. Sollte diese Option aktiviert sein, wird eine Referenzlinie bei Mean(plot(*,y)) gezeigt.
Gesamtmedianlinie zeigen Legen Sie fest, ob die Linie des Gesamtmedians in der Karte gezeigt werden soll. Sollte diese Option aktiviert sein, wird eine Referenzlinie bei Meandian(plot(*,y)) gezeigt.

Registerkarte SD-Diagramm

Standardabweichungsdiagramm zeigen Legen Sie fest, ob unter der Streuungskarte das SD-Diagramm gezeigt werden soll.
Mittelwert der Standardabweichung zeigen Legen Sie fest, ob der Mittelwert der Standardabweichungswerte des letzten Faktors gezeigt werden sollen.
Mittelwertlinien für Faktoren zeigen Wählen Sie den Faktor, für den Sie die Mittelwertlinien auf dem Standardabweichungsdiagramm zeigen möchten. Die Eingabefaktoren werden hier aufgeführt.

Registerkarte Anzeige

Einzelne Datenpunkte zeigen Legen Sie fest, ob die einzelnen Datenpunkte statt nur der Whiskerlinien gezeigt werden sollen. Wenn Sie die Option aktivieren, wird der Boxtyp auf Box + Datenüberschneidung und der Boxstil auf Keine Box gesetzt, falls Box zeigen deaktiviert ist.
Box zeigen Legen Sie fest, ob das Boxdiagramm für jede Gruppe gezeigt werden soll. Durch Aktivieren der Option wird der Boxstil auf Box gesetzt.
Bereichslinie zeigen Legen Sie fest, ob die Linie des Whiskerbereichs für jede Gruppe gezeigt werden soll.
Vorlage Per Standard wird automatisch die Vorlage "variability" verwendet. Wenn Sie eine andere Vorlage verwenden möchten, deaktivieren Sie Auto und navigieren Sie zu der Vorlage.

variability.otpu (installiert im Origin-Programmordner)

Notizen

Die Streuungskarte kann verwendet werden, um die Beziehungen zwischen Faktoren und einer Antwortvariablen zu untersuchen und die Grundursachen für die Streuung zu analysieren. Eine Streuungskarte zeichnet die Daten und Mittelwerte für jede Ebene der Gruppierungsfaktoren mit allen Zeichnungen nebeneinander und Feld für Feld.

Origin zeichnet Streuungskarten für bis zu 4 Faktoren. Sie können selektiv das Standardabweichungsdiagramm in die Streuungskarte zeichnen, das die Standardabweichung für jede Kombination der Faktorebenen zeigt.

Hinweis: Sie können auf die Schaltfläche Verwandte Apps unten im Dialog klicken, um die zugehörige App "Gage Study“ zu prüfen und zu installieren.

Beispiel

In dieem Beispiel wählen wir 2 Faktoren im Feld Faktoren im Dialog plot_vari: "Identification.Classification" und "Identification.Year“ (markiert mit einer roten Box).

Entstapeln Sie die Spalte der Quelldaten mit Faktor 2, einschließlich Spaltenfaktor 1 (markiert mit einer rosa Box). Bei 4 entstapelten Spalten werden die Boxdiagramme nur mit Bereichswhiskern und verbundenen Mittelwertpunkten gezeichnet. Setzen Sie im Dialog Details Zeichnung Faktor 1 als Spalte im Horizontalen Feld auf der Registerkarte Feld, um die Zeichnung in zwei Felder aufzuteilen.

Verwenden Sie die Gruppierungsspalten, um die Anwortspalte der Quelle "City mpg" in 8 Gruppen aufzuteilen und die Standardabweichung für jede Gruppe zu berechnen. Zeichnen Sie diese SD-Werte als ein Punkt-Liniendiagramm unter der Streuungskarte. Sie können sehen, dass die Standardabweichungen in diesem Beispiel relativ konsistent zwischen den zwei Werten ("Automatic transmission" und "Manual transmission") von Faktor 1 schwanken.
