What is Life Science Mode?

Life Science Mode is introduced in Origin 2026b to focus on life science workflows. This mode simplifies Origin interface by hiding most of the graph toolbar buttons and advanced analysis menus, and reorganizes Plot menu to make statistical and biological graphs and analysis more accessible. A dedicated "Data Table" worksheet further simplifies stats plotting and analysis routines. Frequently-used life science file formats such as .XML can be directly imported via drag-and-drop. This mode also pre-installs a collection of popular Apps.

The life science mode keeps only some basic menus and buttons. If you cannot find a tool from the interface, please use search box to find and execute it.

Startup Dialog

To help you get started with Life Science Mode, Origin displays a Startup every time you start Origin or create a new project. This dialog appears with the Samples tab active by default, providing a collection of typical samples with key descriptions, helping you master your analysis routines with ease.

How to Enable Life Science Mode?

  • Enable Life Science Mode during Installation
    When installing Origin, you can select Life Science GUI checkbox on the "Choose additional GUI Modes" page. Selecting Life Science GUI will also preinstall a collection of relevant apps.

    Once installation is complete, Origin will start in Life Science Mode by default.
    Note:

    If you select both Stats GUI and Life Science GUI checkboxes during installation, Origin will start in Life Science Mode.


    Refer to this page for a step-by-step instruction on installing Origin.

  • If you have installed Origin with Default Mode,
    You can switch to Stats Mode by “modifying Origin”:
    1. Open the Windows Start menu and select Repair or Uninstall Origin 20##.
    2. On the Welcome page, select Modify .
    3. Click Next until you reach the "Choose additional GUI Modes" page, then select Life Science GUI checkbox.
    4. Click Next as promoted to complete the installation.

To Swithc back to Default Mode

You can switch back to the classic interface at any time:

  • Select menu Preferences: GUI Mode: Default
