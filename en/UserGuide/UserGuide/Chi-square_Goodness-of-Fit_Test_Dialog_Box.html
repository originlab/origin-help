Supporting Information

To open the Chi-square Goodness-of-Fit Test Dialog:

  1. With a worksheet active, select Statistics: Hypothesis Testing: Chi-square Goodness-of-Fit Test


See Also:

  • Introduction to Chi-square Goodness-of-Fit Test


Input Data Form

Raw Perform the test using raw data column for Category

When you select this option, the Observed Count column in the following table is unable to be edited. And this option is available for the dataset imported from worksheet column. Select a raw data column for Category, then the Observed value will be counted auto and filled in the table. Then you can customize the Expected data.

Summarized Perform the test using summarized data for the Observed Count and Expected.

Significance Level

Set the significance level for Chi-square Goodness-of-Fit Test

Reset Table

Clear all content in the following table.

Table

Input dataset in the table by these two methods:

  • Enter the data in the table directly.
  • Click the button in the header to select and import a column dataset in the Worksheet.
Category Specify the name of the tested groups(rows).
Observed Count When Input Data Form is Summarized, this column is able to be edited.

Specify the actual number of the observed value for each category.

Expected Specify the expected value for each category.

Click the drop-down list under the Expected in the column header, it can change the the types of the expected. The expected data should be one of the following types:

  • Equal Proportion (1/k)
When select this option the expected value not need to be entered. It will auto calculated by 1 divided by the number of categories(rows) to be tested.
  • Proportion (0-1)
The sum of expected fraction must be 1.
  • Counts
The total of the observed count and the expected count must be equal.
  • Percentage (%)
The sum of expected percentages must equal 100.
