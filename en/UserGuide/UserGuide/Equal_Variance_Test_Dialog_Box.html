Supporting Information

To open the Equal Variance Test Dialog:

  1. With a worksheet active, select Statistics: Hypothesis Testing: Equal Variance Test

For more information, see: Recalculating Analysis Results

Input

Equal Variance Test supports Indexed and Raw two input data form.

For help with range controls, see: Specifying Your Input Data

Indexed Data The input data consists of one sample data column and one or more grouping column. Factor variable and response data are stored in separate columns.
  • Data
The sample data column.
  • Group By
The grouping column.
Raw Data The input data consists of at least two sample data columns. Each column contains response data from a level of factor variable.
  • Sample
Specify columns as the sample dataset. (at least 2 columns.)

Significance Level

Set the significance level for Equal Variance Test

Assume Normal Distribution

  • If uncheck this option, it will use the Bonnet Multiple comparisons, Brown-Forsythe, Levene (Squared Deviations) and Levene (Absolute Deviations) methods in the test, and output the P-value for them. The Comparison Intervals for SD graph will be output the Graphical Summary Report.
  • If check this option, it will use the F test for the data with two groups, or Bartlett method for the data with three or more groups, and output the P-value. The 95% Bonferroni Confidence Intervals for SD graph will be output the Graphical Summary Report, and the Normal Probability Plot will be shown in the Diagnostic branch.

Plots

The selected graph will be shown after Diagnostic branch, if Graphical Diagnostic Report is selected in the Output tab.

Bonett Multiple Comparison Intervals for SD When Assume Normal Distribution in the Input tab is uncheck, this option available.

Create a Bonett Multiple Comparison Intervals for SD

Box Chart Create a box chart.

Output

For help with the range controls, see: Output Results

Graphical Summary Report Create a summary graph report, including P value bar, effect size bar and data distribution graph. The result tables will also been attached to the graph to show the statistical values.

The footnote after the summary graph will diagnose these statistical results.

Graphical Diagnostic Report Specify whether to display the graphical diagnostic report.

The Run Chart for the Outlier Detect and Individual Value Plot for the Distribution are shown in this report.

If Assume Normal Distribution (in the Input tab ) is selected, the Normal Probability Plot will be shown in the Diagnostic branch.

Plot Data Specify the worksheet for output the plot datasets.
Result Specify the worksheet for output of test results


Note:
  • The Masked Data and Bad Data(missing value) table will be in the report sheet.
