Brief Description

Operational model for receptor depletion when X is concentration or dose.

Sample Curve

Parameters

Number: 5

Names:Em, B, Ka, Tau, n

Meanings: Em=maximum possible system response, B=response without agonist, Ka=agonist-receptor dissociation constant, Tau=dissociation constant, n=transducer ratio

Lower Bounds: none

Upper Bounds: none

Derived Parameters

logTau=log(Tau)

logKa=log(Ka)
