2.9 Origin GUI Modes

GUI-Modes

Origin offers 3 GUI modes when during installation:

  • Default mode: prvides Origin's classic interface with the full set of menus, toolbars, buttons, and graphing options.
  • Stats mode: pre-installs a collection of apps and provides an interface tailored to statistical analysis and quality-control workflows.
  • Life Science mode: pre-installs a collection of apps and provides an interface to streamline pharmacological and biological assay workflows, such as dose-response, ANOVA and survival analysis.
  • Compact mode: streamlines the workspace, reduces and reorganizes buttons to make an ease-of-use interface for novice users.


Therefore...

if you cannot find a menu or button, or have difficulty following instructions in our documentation,

1. check if Origin is running in Stats mode or Life Science mode

  • you can check the current GUI mode by menu Preferences: GUI Mode:
If Stats mode is enable... If Life Science mode is enable...

2. If Origin is running in either mode, you can:

Switch to Default mode

To switch to Default mode, select menu Preferences: GUI Mode: Default.

OR,

Use Search bar

Enter the name of a menu, button, or app in Search bar next to main menu to find and run it.
