Input

One-Sample Variance Test supports Raw, Summarized Data(SD) and Summarized Data(Variance) three input data form.

Raw Enter column with range format.

For help with range controls, see: Specifying Your Input Data

Summarized Data (SD) Summarized Data is standard derivation and sample size prepared for samples.

Enter following Summarized Data by selecting columns from worksheet or entering into the dialog box manually.

  • Sample Name
Specify name of the samples. You can specify a column as sample name, or enter space separated strings, or leave it empty.
  • SD
Specify the standard derivation of the data. You can specify a column dataset, or enter space separated number. (SD should be greater than 0.)
  • Sample Size
Specify the total number of data. You can specify a column dataset, or enter space separated number. (Sample size should be greater than 0.)
Summarized Data (Variance) Summarized Data is Variance and sample size prepared for samples.

Enter following Summarized Data by selecting columns from worksheet or entering into the dialog box manually.

  • Sample Name
Specify name of the samples. You can specify a column as sample name, or enter space separated strings, or leave it empty.
  • Variance
Specify the Variance of the data. You can specify a column dataset, or enter space separated number.
  • Sample Size
Specify the total number of data. You can specify a column dataset, or enter space separated number. (Sample size should be greater than 0.)

Test

Test for Options:
  • Variance
  • Standard Deviation (Default option)
Test Variance If select Variance in Test for drop-down list, you can specify the hypothetical variance to be tested.
Test SD If select Standard Deviation in Test for drop-down list, you can specify the hypothetical SD to be tested.
Null Hypothesis The null hypothesis to be tested (i.e. sample variance = Test Variance).
Alternate Hypothesis Options:
Variance <> Test Variance or SD <> Test SD
The sample variance/SD differs from the hypothetical variance/SD.
Variance > Test Variance or SD > Test SD
The sample variance/SD is larger than the hypothetical variance/SD (upper-tailed test).
Variance < Test Variance or SD < Test SD
The sample variance/SD is less than the hypothetical variance/SD (lower-tailed test).
Significance Level The significance level of the test.
Confidence Interval(s) Compute confidence intervals for sample variance.
Confidence Level(s) in % Specify space-separated confidence levels (%). This option is only available when Confidence Interval(s) is selected.
Test Method Select test method
  • Chi-Square
It is only for the normal distribution. It will output the Chi-Square test result with Chi-Square, DF and Prob>Chi-Square, and the Confidence Intervals for Variance/Standard Deviation .
  • Bonett
If is for any continuous distribution. It will output the Bonett test result with P-Value, and the Confidence Intervals for Variance/Standard Deviation.
When input data form is Summarized Data(SD)/(Variance), Bonett option is disable.

Power Analysis

Unset Minimal Difference of Interest

Difference(s) for Specified Power When Minimal Difference of Interest is not set, this option is available.

Output the differences for the specified power levels. When this option is selected, the specified power levels setting will affect the power level in power curve.

Power Level(s) When check the Difference(s) for Specified Power option, you can enter the power levels separated by space in this edit box. Default power levels are 60%, 70%, 80% and 90%.

Set Minimal Difference of Interest

Minimal Difference of Interest Specify the minimum difference from the test variance/SD and the target variance/SD. Once you enter a value in this box, the Power Analysis graph will show the minimum sample size to detect this difference in the different powers.
Sample Size(s) for Specified Power When check the Minimal Difference of Interest option, this option is available.

Output the Sample Sizes for the specified power levels. When this option is selected, the specified power levels setting will affect the power level in power curve. If it is selected, it will use the default power levels.

Power Level(s) When check the Sample Size(s) for Specified Power option, you can enter the target power levels separated by space in this edit box. Default power levels are 60%, 70%, 80% and 90%.
Power Based on Test Data When specify the Minimal Difference of Interest, this option is available.

Compute the power for the sample size of the test data. (the probability of rejecting the null hypothesis when it is false).

Hypothetical Power When specify the Minimal Difference of Interest, this option is available.

Compute the power of the test at various sample sizes. When check this option, it will add corresponding curve to power curve.

Hypothetical Sample Size(s) When specify the Minimal Difference of Interest and Hypothetical Power is checked, this option is available.

Specify hypothetical sample size(s) for power computation.

Plots

Histogram Plot a histogram of sample data.
Box Chart Plot a box chart of sample data.

Note: When outlier(s) detected in the datasets, a footnote will show under the Box chart to note you to review their case. If you want to exclude the outliers, you can click the triangle button at the end of the footnote to mark outliers and recalculate.

Arrange Plots of Same Type in One Graph Put the plots of same type in one graph. Note that for histograms, the layers will be arranged vertically; for box charts, layers will be arranged horizontally.
Note: When input data form is Summarized Data(SD)/(Variance), it will not output above plots.

Output

Results Log Output

Select to output results to the Results Log.

Graphical Summary Report Create a summary graph report, including P value bar, effect size bar and data distribution graph. The result tables will also been attached to the graph to show the statistical values.

The footnote after the summary graph will diagnose these statistical results.

Graphical Power Analysis Report Specify whether to display the graphical Power Analysis report. The power curve shows how the statistical power of the test changes as the difference in proportions varies. Power is the probability of rejecting the null hypothesis when the true difference differs from 0.

A footnote will be added after the power curve graph to show you the diagnosis results of power analysis. A power value of 80% is usually considered sufficient.

Output Plot Data Specify a worksheet for output of plotted data (Origin generates tabular data when plots are created).
Output Results Specify the worksheet for output of test results.
Note:
  • When input data form is Summarized Data(SD)/(Variance), Graphical Summary report will not be output.
  • When input multiple data (both Raw and Summarized Data), Graphical Power Analysis report will not be output.
  • When input data form is Raw, Masked Data and Bad Data(missing value) table will be in the report sheet.
