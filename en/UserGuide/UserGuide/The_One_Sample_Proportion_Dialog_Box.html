Input

One-Sample Proportion Test supports Raw and Summarized Data two input data form.

Summarized Perform the test using summary statistics that you enter into the dialog box manually.
  • Number of Events
The observed number of events.
  • Sample Size
The total number of observations.
Raw Perform the test using a dataset composed of "success" or "failure" values. The dataset must contain no more than two distinct values.

For help with range controls, see: Specifying Your Input Data

  • Sample
Define a sample data range.
  • Event
The dataset value that denotes event.

Proportion Test

Test Proportion The hypothetical proportion to be tested.
Null Hypothesis The null hypothesis to be tested (Sample Proportion = Test Proportion).
Alternative Hypothesis Options:
  • Proportion <> Test Proportion
A two-tailed proportion test that seeks to answer whether the sampled proportion = Test Proportion.
  • Proportion > Test Proportion
An upper-tailed proportion test that seeks to answer whether the sampled proportion is larger than the Test Proportion.
  • Proportion < Test Proportion
A lower-tailed proportion test that seeks to answer whether the sampled proportion is less than the hypothetical proportion .
Significance Level The significance level of the test.
Confidence Interval(s) Compute confidence interval for the true (population) proportion.
Confidence Level(s) in % Specifies the confidence levels for which the confidence intervals will be computed. This option is only available when Confidence Interval(s) is selected.
Test Methods Origin uses two methods for computing p values and confidence intervals for one-sample proportion tests (for documentation of Normal Approximation and Binomial test, see the algorithms page)
  • Normal Approximation
The Normal Approximation is always calculated. Generally gives a satisfactory result when successes is ≥ 10 and when sample size - successes is ≥ 10. The quality of the approximation tends to improve as sample size increases.
For small sample sizes or extreme underlying proportions ( close to 0 or 1), the normal approximation degrades.
  • Binomial Exact Test
Binomial Test uses the probability mass function of the binomial distribution directly, solving for the upper and lower bounds by separately setting each tail probability to
This method adopts an ultra-conservative strategy. It produces overly wide confidence intervals and lower statistical power for hypothesis testing. And it is suitable for data with small sample size .
  • Adjust Blaker's Exact Test
Blaker's Exact Test considers both tails jointly, significantly reducing unnecessary interval width. The Adjusted version further optimizes the algorithms, resolving numerical boundary issues and ensuring strict matching between p-values and confidence intervals.
Compared to Normal Approximation and Binomial Exact Test, Adjust Blaker's Exact Test combines exactness with conciseness: It remains a strictly exact method (actual coverage rate ), yet yields narrower confidence intervals and higher statistical power than Binomial Exact Test.

Power Analysis

Unset Minimal Difference of Interest

Difference(s) for Specified Power When Minimal Difference of Interest is not set, this option is available.

Output the differences for the specified power levels. When this option is selected, the specified power levels setting will affect the power level in power curve.

Power Level(s) When check the Difference(s) for Specified Power option, you can enter the power levels separated by space in this edit box. Default power levels are 60%, 70%, 80% and 90%.

Set Minimal Difference of Interest

Minimal Difference of Interest (MDI) Specify the minimum difference you are interested in. Once you enter a value in this box, the Power Analysis graph will show the minimum sample size to detect this difference in the different powers.
Note:

For One Sample Proportion test, there is a limitation for the Minimal Difference of Interest (MDI) setting. That is related to the Test Proportion which is specified in Proportion Test tab.

  • When Proportion <> Test Proportion, MDI value should be a positive value less than the max value between Test Proportion and 1-Test Proportion.
  • When Proportion > Test Proportion, MDI value should be a positive value less than 1-Test Proportion.
  • When Proportion < Test Proportion, MDI value should be a positive value less than Test Proportion.
Sample Size(s) for Specified Power When check the Minimal Difference of Interest option, this option is available.

Output the Sample Sizes for the specified power levels. When this option is selected, the specified power levels setting will affect the power level in power curve. If it is selected, it will use the default power levels.

Power Level(s) When check the Sample Size(s) for Specified Power option, you can enter the target power levels separated by space in this edit box. Default power levels are 60%, 70%, 80% and 90%.
Power Based on Test Data When specify the Minimal Difference of Interest, this option is available.

Compute the power for the sample size of the test data. (the probability of rejecting the null hypothesis when it is false).

Hypothetical Power When specify the Minimal Difference of Interest, this option is available.

Compute the power of the test at various sample sizes. When check this option, it will add corresponding curve to power curve.

Hypothetical Sample Size(s) When specify the Minimal Difference of Interest and Hypothetical Power is checked, this option is available.

Specify hypothetical sample size(s) for power computation.

Output

For help with the range controls, see: Output Results

Results Log Output Select to output results to the Results Log.
Graphical Summary Report Specify whether to display the graphical summary report
Graphical Power Analysis Report Specify whether to display the graphical Power Analysis report. The power curve shows how the statistical power of the test changes as the difference in proportions varies. Power is the probability of rejecting the null hypothesis when the true difference differs from 0.

A footnote will be added after the power curve graph to show you the diagnosis results of power analysis.

Output Results Specify the worksheet for output of test results
Output Plot Data Specify the worksheet for output the plot datasets.
