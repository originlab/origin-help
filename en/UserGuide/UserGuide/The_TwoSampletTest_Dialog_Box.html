Input

Two-Sample t-Test supports Indexed, Raw and Summarized Data three input data form.

Indexed The input data consists of one sample data column and one grouping column. Factor variable and response data are stored in separate columns.

For help with range controls, see: Specifying Your Input Data

  • Group Range
The grouping column. Note that the grouping column will be set as categorical if Text column.
  • Data Range
The sample data column.
Raw The input data consists of two sample data columns. Each column contains response data from a level of factor variable.

For help with range controls, see: Specifying Your Input Data

  • 1st Data Range
The first sample column.
  • 2nd Data Range
The second sample column.
Summarized Data Summarized Data is mean, standard derivation and sample size prepared for samples. Perform the test using summary statistics that you select columns from worksheet or enter into the dialog box manually.

Enter following Summarized Data by selecting columns from worksheet or entering into the dialog box manually.

  • Sample Name
Specify name of the samples. You can specify a column as sample name, or enter space separated strings, or leave it empty.
  • Mean
Specify the mean of the data. You can specify the a column dataset, or enter space separated number.
  • SD
Specify the standard derivation of the data. You can specify a column dataset, or enter space separated number. (SD should be greater than 0.)
  • Sample Size
Specify the total number of data. You can specify a column dataset, or enter space separated number. (Sample size should be greater than 0.)

t-Test for Mean

Test Mean The hypothetical mean to be tested (0 if testing equality of means).
Null Hypothesis The null hypothesis: No difference between Mean1 and Mean2.
Alternate Hypothesis The alternate hypothesis:

Mean1 - Mean2 <> Test Mean Difference

Used for two-tailed two-sample test. Mean1 and Mean2 differ.

Mean1 - Mean2 > Test Mean Difference

Used for an upper-tailed two-sample test. Test Mean1 is greater than Mean2.

Mean1 - Mean2 < Test Mean Difference

Used for a lower-tailed two-sample test. Test Mean1 is less than Mean2.
Significance Level Specify the significance level.
Effect Size Calculate Cohen's d value to show the effect size which is the magnitude of the difference between actual mean difference "Mean1 - Mean2" and Test Mean you specified.
Confidence Interval(s) Compute confidence intervals for the differences of the means.

For computation details, see Algorithms (Two-Sample T-Test).

Confidence Level(s) in % Enter space-separated confidence levels. This option is only available when Confidence Interval(s) is chosen.
Equal Variance Assumed Choose whether assume the equal variances.

When the variances of the two samples are equal or when the same sizes are same, you can check this check box; when the variances are not equal or when the sample sizes are very different, please uncheck this check box to avoid the serious error.


Power Analysis

Unset Minimal Difference of Interest

Difference(s) for Specified Power When Minimal Difference of Interest is not set, this option is available.

Output the differences for the specified power levels. When this option is selected, the specified power levels setting will affect the power level in power curve.

Power Level(s) When check the Difference(s) for Specified Power option, you can enter the power levels separated by space in this edit box. Default power levels are 60%, 70%, 80% and 90%.

Set Minimal Difference of Interest

Minimal Difference of Interest Specify the minimum difference from two samples test mean that you are interested in. Once you enter a value in this box, the Power Analysis graph will show the minimum sample size to detect this difference in the different powers.
Sample Size(s) for Specified Power When check the Minimal Difference of Interest option, this option is available.

Output the Sample Sizes for the specified power levels. When this option is selected, the specified power levels setting will affect the power level in power curve. If it is selected, it will use the default power levels.

Power Level(s) When check the Sample Size(s) for Specified Power option, you can enter the target power levels separated by space in this edit box. Default power levels are 60%, 70%, 80% and 90%.
Power Based on Test Data When specify the Minimal Difference of Interest, this option is available.

Compute the power for the sample size of the test data. (the probability of rejecting the null hypothesis when it is false).

Hypothetical Power When specify the Minimal Difference of Interest, this option is available.

Compute the power of the test at various sample sizes. When check this option, it will add corresponding curve to power curve.

Hypothetical Sample Size(s) When specify the Minimal Difference of Interest and Hypothetical Power is checked, this option is available.

Specify hypothetical sample size(s) for power computation.

Plots

Probability Plot Plot a probability plot.
Box Chart Plot a box chart.

Note: When outlier(s) detected in the datasets, a footnote will show under the Box chart to note you to review their case. If you want to exclude the outliers, you can click the triangle button at the end of the footnote to mark outliers and recalculate.

Histogram Plot a histogram.
Arrange Plots of Same Type in One Graph Note that for histograms, the layers will be arranged vertically. For box charts, layers will be arranged horizontally.
Note: When input data form is Summarized Data, it will not output above plots.

Output

For help with the range controls, see: Output Results

Results Log Output

Select to output results to the Results Log.

Graphical Summary Report Create a summary graph report, including P value bar, effect size bar and data distribution graph. The result tables will also been attached to the graph to show the statistical values.

The footnote after the summary graph will diagnose these statistical results.

Graphical Power Analysis Report Create a graphical power analysis report with power curve(s). The output table and power curves are according to the setting in the Power Analysis tab.
  • If no value has been set for Minimal Difference of Interest editbox, only the power curve of current sample size will be output; and the power at 60%, 70%, 80% and 90% (default value) will be tagged to show the difference at these power values.
  • If a difference value has been set for Minimal Difference of Interest editbox, the power curves will be output: power curves at around 60%, 70%, 80% and 90% (default value) and current sample size; and the sample size to detect the minimal difference will be listed.

A footnote will be added after the power curve graph to show you the diagnosis results of power analysis. A power value of 80% is usually considered sufficient.

Output Plot Data Specify a worksheet for output of plotted data (Origin generates tabular data when plots are created).

This item is only available when the Input Data Form is Raw.

Output Results Specify the worksheet for output of test results.
Note:
  • When input data form is Summarized Data, Graphical Summary report will not be output.
  • When input data form is Raw or Indexed, Masked Data and Bad Data(missing value) table will be in the report sheet.
