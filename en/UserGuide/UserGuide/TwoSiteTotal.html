Function

Brief Description

Two sites total binding function.

Sample Curve

Parameters

Number: 6

Names: Bg, NS, Bmax1, Bmax2, K1, K2

Meanings: Bg=y value at x is 0, NS=slope, Bmax1=first top asymptote, Bmax2=second top asymptote, K1=first equilibrium dissociation constant, K2 =second equilibrium dissociation constant

Lower Bounds: K1>0, K2>0

Upper Bounds: none

Derived Parameters

AffinityRatio=K2/K1

PercentHighAffinity=100*Bmax1/(Bmax1+Bmax2)

Script Access
