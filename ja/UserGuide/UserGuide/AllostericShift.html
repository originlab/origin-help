説明

Xが濃度または用量の場合のアロステリックEC50シフト。

サンプル曲線

パラメータ

パラメータ数:  7

パラメータ名: B, KB, alpha, Bt, Tp, EC50, s

意味: B = モジュレーター濃度、KB = 平衡解離定数、alpha = 三元複合体定数、Bt = 下側漸近線、Tp = 上側漸近線、EC50 = 半最大応答を示すアゴニスト濃度、s = Hill勾配

下側境界: なし

上側境界: なし

派生パラメータ

logKB=log(KB)

logEC50=log(EC50)

logAlpha=log(alpha)

スクリプトでのアクセス法

nlf_AllostericShift(x,B,KB,alpha,Bt,Tp,EC50,s)
