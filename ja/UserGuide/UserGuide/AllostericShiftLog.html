説明

log(X)を使用したアロステリックEC50シフト関数

サンプル曲線

パラメータ

パラメータ数:  7

パラメータ名: LogEC50, LogKb, Logalpha, B, A1, A2, p

意味：LogEC50 = モジュレーターなしで半最大応答を示すアゴニスト濃度の対数、LogKb = 平衡解離定数の対数、Logalpha = 三元複合体定数の対数、B = モジュレーター濃度、A1 = 下側漸近線、A2 = 上側漸近線、p = Hill勾配

下側境界: なし

上側境界: なし

派生パラメータ

Kb=10^LogKb

スクリプトでのアクセス法

nlf_AllostericShiftLog(x,LogEC50,LogKb,Logalpha,B,A1,A2,p)
