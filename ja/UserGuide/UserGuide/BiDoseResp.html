説明

二相性用量反応関数。

サンプル曲線

パラメータ

パラメータ数:  7

パラメータの名前: A1, A2, LOGx01, LOGx02, h1, h2, p

意味: A1 = 下限、A2 = 上限、LOGx01 = 第1のEC50、LOGx02 = 第2のEC50、h1 = 勾配1、h2 = 勾配2、p = 比率

下側境界: なし

上側境界: なし

派生パラメータ

スパン:

Span=abs(A1-A2)

半最大応答を示す濃度:

EC50_1=10^(LOGx01)

EC50_2=10^(LOGx02)

スクリプトでのアクセス法
