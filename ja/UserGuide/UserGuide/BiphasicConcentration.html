関数

説明

2つの促進性用量反応曲線、または2つの阻害性用量反応曲線の和をフィットします。

サンプル曲線

パラメータ

パラメータ数:  7

パラメータの名前: Bt, Tp, EC501, EC502, s1, s2, p

意味: Bt = 曲線左端のプラトー、Tp = 曲線右端のプラトー、EC501 = 半最大応答を示す濃度、EC502 = 半最大応答を示す濃度、s1 = Hill勾配、s2 = Hill勾配、p = 最大応答の比率

下側境界: p>0

下側境界: p<1

スクリプトでのアクセス法

nlf_BiphasicConcentration(x,Bt,Tp,EC501,EC502,s1,s2,p)
