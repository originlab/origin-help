説明

Xが濃度の場合のGaddum/Schild EC50シフト。

サンプル曲線

パラメータ

パラメータ数:  7

パラメータの名前: Bt, Tp, EC50, HS, SS, B, p

意味: Bt = 下側プラトー、Tp = 上側プラトー、EC50 = 半最大応答を示す濃度、HS = Hill勾配、SS = Schild勾配、B = アンタゴニスト濃度、p = A2の負の対数

下側境界: なし

上側境界: なし

派生パラメータ

logEC50=log(EC50)

logA2=-p

スクリプトでのアクセス法
