関数

説明

アロステリック調節因子のシフトを伴う単一部位結合モデル。

サンプル曲線

パラメータ

パラメータ数:  5

パラメータ名: logalpha, logKb, KdHot, Allo, Bmax

意味： logalpha = 協同性定数の対数、logKb = 平衡解離定数の対数、KdHot = 放射性リガンドの平衡解離定数、Allo = アロステリックモジュレーター、Bmax = 上側漸近線

下側境界: なし

上側境界: なし

派生パラメータ

alpha=10^logalpha

Kb=10^logKb

スクリプトでのアクセス法

nlf_OneSiteAlloModShift(x,logalpha,logKb,KdHot,Allo,Bmax)
