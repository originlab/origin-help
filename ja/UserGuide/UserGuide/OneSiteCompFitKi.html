関数


説明

単一部位競合結合曲線。Hill勾配を-1とする用量反応曲線。

サンプル曲線

パラメータ

パラメータ数:  5

パラメータの名前: A1, A2, logKi, H1, H2

意味: A1 = 上側漸近線、A2 = 下側漸近線、llogKi = Kiの常用対数（log10 Ki）、H1 = 標識リガンド、H2 = 標識リガンドの平衡解離定数（Kd）

下側境界: なし

上側境界: なし

派生パラメータ

Ki=10^(logKi)

EC50=10^(logKi)*(1+H1/H2)

スクリプトでのアクセス法

nlf_OneSiteCompFitKi(x,A1,A2,logKi,H1,H2)
