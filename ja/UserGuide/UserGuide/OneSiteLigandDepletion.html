説明

放射性リガンドの枯渇を考慮した単一部位競合結合モデル。

サンプル曲線

パラメータ

パラメータ数:  7

パラメータ名: logKi, Bmax, NS, Hot, KdNM, SpAct, Vol

意味： logKi = Kiの常用対数（log10 Ki）、 Bma = 上側漸近線、 NS = 非特異的結合の割合、 Hot = 放射性リガンド、 KdN = 標識リガンドの平衡解離定数（Kd）、 SpAct = 比放射能、 Vol = 反応体積

下側境界: なし

上側境界: なし

派生パラメータ

Ki=10^(logKi)

スクリプトでのアクセス法
