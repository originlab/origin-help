入力データ

入力データ形式
  • 要約
ワークシート内の実際のサンプルデータではなく、集計統計量を使用して検定を実行します。これらの値は、ダイアログボックスに手動で入力できます。
  • 素データ値
列のデータセットを使用して検定を実行します。
入力データ

(要約)

  • サンプルサイズ
観測値の合計数です。
  • 総発生数
標本でイベントが発生した回数です。
入力データ

(素データ値 )

  • サンプル
サンプルデータセットとして列を指定します。
  • 頻度
これはオプションです。標本列の値が出現した回数を集計した度数列です。
曝露 カウントデータの観測期間を指定します。たとえば、時間、面積、体積、項目数などです。 デフォルトでは、1に設定されています。

ポアソン率検定

検定率 検定する仮説上の率です。
帰無仮説 検定される帰無仮説（率 = 検定率）。
対立仮説 オプション：
率 <> 検定率
標本率 = 検定率 であるかどうかを調べる両側ポアソン率検定です。
率 > 検定率
標本率が 検定率より大きいかどうかを調べる上側片側ポアソン率検定です。
率 < 検定率
標本率が仮定率より小さいかどうかを調べる下側片側ポアソン率検定です。
有意水準 検定の有意水準。
信頼区間 真の（母集団）率の信頼区間を計算します。
%単位での信頼水準 信頼区間を計算する信頼水準を指定します。このオプションは信頼区間が選択されている場合にのみ利用可能です。

検定方法

Originでは、1標本ポアソン率検定の p 値および信頼区間の計算に、次の2つの方法を使用します。

正確 正確法を使用する場合、サンプルサイズに関する要件はありません。小さいサンプルや低頻度イベントに適しています。
正規近似 正規近似は常に計算されます。近似の精度は、サンプルサイズが大きくなるほど向上する傾向があります。
