繰り返しのある一元配置分散分析 ダイアログボックス

OneWayRMANOVA-Dialog

このダイアログは、繰り返しのある一元配置の分散分析（one-way Repeated Measure ANOVA）を実行するために使用します。このダイアログを開くには、メニューから統計：ANOVA：一元配置（繰り返し測定）と選択します。

平均比較

後処理のペアワイズ平均比較の方法を選択します。

有意水準 ペアワイズ平均比較の有意水準を指定します。
比較
  • すべての平均の組み合わせ
すべてのグループを、他のすべてのグループと比較します。
  • 各平均と対照
特定の1グループを基準（対照水準）として選択し、その他のすべてのグループをこのグループと比較します。対照以外のグループ同士は比較しません。
対照水準 平均比較を行う際の対照水準を指定します。このオプションは、比較で各平均を対照を選択した場合に使用できます。

たとえば、標本にA, B, C の3つの水準（グループ）があり、対照水準として A を指定した場合、B と C はそれぞれ A と比較されますが、B と C は互いに比較されません。


Tukey

ペアワイズ平均比較のための異なる方法です。

入力タブで等分散を仮定を選択した場合、ペアごとの平均比較に以下の方法を使用できます。

比較ですべての平均の組み合わせを選択した場合は、Tukey法を使用できます。 各平均と対照を比較で選択した場合は、Dunnett法を使用できます。 その他の方法は、どちらの比較方法でも使用できます。 （詳細はアルゴリズムを参照してください）

Dunnett
Bonferroni
Dunn-Sidak
Fisher LSD
Scheffe
Holm-Bonferroni
Holm-Sidak
グループ化文字表 平均値の差を文字で示します。同じ文字は有意差がないことを示し、異なる文字は2つのグループ間に有意差があることを示します。
