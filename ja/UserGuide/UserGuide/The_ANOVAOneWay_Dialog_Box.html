インデックス このモードでは、1つの列に因子変数のレベルが含まれ、対応する応答データは別の列に含まれます。

因子

因子列を指定します。因子列がテキスト列の場合、カテゴリー列に設定されます。

データ

応答データの列を指定します。

素データ値 このモードでは、各因子変数のレベルからの応答データが別々の列に格納されます。

記述統計

出力レポートに記述統計の結果を含めるかどうかを選択します。

効果量

レポートシートに効果量を出力するかどうかを指定します。レポートテーブルには、一元配置ANOVAの効果量指標として、イータ二乗、コーエンのf、オメガ二乗が出力されます。これらはすべて、ANOVAにおけるグループ間の差の大きさを定量化するために使用される標準化された効果量統計量です。

イータ二乗とオメガ二乗は分散説明率を表す指標で、コーエンのfは標準化された平均差の指標です。

有意水準

一元配置分散分析の有意水準を指定します。

等分散を仮定

このチェックボックスはデフォルトで選択されています。これは、平均比較タブで提供されるメソッドに影響します。

標準的なANOVAでは、比較するすべてのグループの分散が等しいことを仮定します。一方、WelchのANOVAは、等分散性の仮定が満たされない場合に使用できる、標準的な一元配置ANOVAの代替手法です。グループごとの分散を重み付けして自由度を調整することで、グループ間で分散や標本サイズが大きく異なる場合でも、第1種の過誤率を安定して維持します。

  • このオプションを選択した場合、全般ANOVAレポートテーブルが出力されます。また、平均比較法として、Tukey、Dunnet、Bonferroni、Dunn-Sidak、Fisher LSD、Scheffe、Holm-Bonferroni、Holm-Sidakを使用できます。
  • このオプションが選択されていない場合、Welchの検定レポートテーブルが出力されます。また、平均比較法としてGames-Howellを使用できます。さらに、結果シートのサマリグラフでは、P値はWelchのANOVAのP値に基づき、平均の比較区間はGames-Howell法に基づいています。

平均比較

後処理のペアワイズ平均比較の方法を選択します：

有意水準 ペアワイズ平均比較の有意水準を指定します。
比較
  • すべての平均の組み合わせ
すべてのグループを、他のすべてのグループと比較します。
  • 各平均と対照
特定の1グループを基準（対照水準）として選択し、その他のすべてのグループをこのグループと比較します。対照以外のグループ同士は比較しません。
対照水準 平均比較を行う際の対照水準を指定します。このオプションは、比較で各平均を対照を選択した場合に使用できます。

たとえば、標本にA, B, C の3つの水準（グループ）があり、対照水準として A を指定した場合、B と C はそれぞれ A と比較されますが、B と C は互いに比較されません。

Tukey

平均比較に使用する方法を指定します。

入力タブで等分散を仮定を選択した場合、ペアごとの平均比較に以下の方法を使用できます。

比較ですべての平均の組み合わせを選択した場合は、Tukey法を使用できます。 各平均と対照を比較で選択した場合は、Dunnett法を使用できます。 その他の方法は、どちらの比較方法でも使用できます。

検出力解析

検出力解析を実行する場合選択します。

最小関心差を設定しない場合

指定した検出力に対する差 最小関心差が設定されていない場合、このオプションを使用できます。

指定した検出力レベルに対応する差を出力します。このオプションを選択すると、指定した検出力レベルの設定が、検出力曲線内の検出力レベルに反映されます。

検出力レベル 指定した検出力に対する差オプションをオンにした場合、この編集ボックスに検出力水準をスペース区切りで入力できます。デフォルトの検出力水準は 60%、70%、80%、90% です。

最小関心差を設定する場合

関心のある最小差 関心のある最小の差を指定します。このボックスに値を入力すると、検出力分析グラフには、異なる検出力でこの差を検出するために必要な最小標本サイズが表示されます。
指定された検出力のサンプルサイズ 関心のある最小差にチェックを付けた場合に使用できます。

指定した検出力レベルに対応する標本サイズを出力します。このオプションを選択すると、指定した検出力レベルの設定が、検出力曲線内の検出力レベルに反映されます。選択しない場合は、デフォルトの検出力レベルが使用されます。

検出力レベル 指定した検出力に対する標本サイズオプションをオンにした場合、この編集ボックスに検出力水準をスペース区切りで入力できます。デフォルトの検出力水準は 60%、70%、80%、90% です。
検定データに基づく検出力 関心のある最小差を指定した場合に使用できます。

検定データのサンプルサイズでの検出力を計算します。 （帰無仮説が偽であるときに帰無仮説を棄却する確率）

仮説の検出力 関心のある最小差を指定した場合に使用できます。

サンプルサイズを変化させた場合の検出力を計算します。このオプションにチェックを付けると、対応する曲線が検出力曲線に追加されます。

仮説のサンプルサイズ 関心のある最小差を指定し、仮説の検出力をオンにした場合、このオプションを使用できます。

検出力計算のための仮想サンプルサイズを指定します。

出力

グラフィカル要約レポート グラフィカル要約レポートを表示するかどうかを指定します。
レポートで使用した平均比較法 グラフィカル要約レポートにチェックを付け、入力タブで等分散を仮定にチェックを付けた場合、このオプションを使用できます。平均の比較間隔の方法を選択します。

グラフィカル要約レポートがチェックされている場合、このオプションは表示されません。平均の比較間隔の方法はGames-Howellです。

グラフィカル診断レポート 診断レポートを表示するかどうかを指定します。

グラフィカル要約レポートが表示されている場合、レポートの後のグラフノードに表示されます。グラフィカル要約レポートが表示されない場合は最初のグラフノードに表示されます。

標本サイズは、左パネルのデータの分布に表示されるプロットタイプに影響します。

  • 1つの因子の標本サイズが30以上の場合、ヒストグラム + 区間プロットが表示されます。
  • 1つの因子の標本サイズが30未満の場合、ドット + 区間プロットが表示されます。
  • 因子の数が6を超える場合、ヒストグラムまたはドットプロットのみが表示され、区間プロットは非表示になります。
グラフィカル検出力解析レポート 検出力解析レポートをグラフィカルに表示するかどうかを指定します。検出力曲線は、比率の差の変化に応じて検定の統計的検出力がどのように変化するかを示します。検出力とは、真の差が0と異なる場合に帰無仮説を棄却する確率です。
