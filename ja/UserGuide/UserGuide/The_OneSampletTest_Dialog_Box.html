入力

1群のt検定は、素データと要約データの2つの入力データ形式に対応しています。

素データ値 範囲形式の列を使用して検定を実行します。各列には、因子変数の各水準に対応する応答データが含まれます。

範囲の設定に関する詳細は、入力データを指定するをご覧ください。

要約データ 要約データは、サンプルに用意された平均値、標準偏差、四分位、サンプルサイズです。 複数の要約データをサポートしています。

ワークシートの列を選択するか、手動でダイアログボックスに要約データを入力します。

  • サンプル名
サンプルの名前を指定します。列をサンプル名として指定するか、スペースで区切った文字列を入力します。あるいは、空のままにします。
  • 平均
データの平均を指定します。 列データセットを指定するか、スペース区切りの値を入力します。
  • SD
データの標準導出を指定します。 列データセットを指定するか、スペース区切りの値を入力します。（SDは0より大きい必要があります。）
  • サンプルサイズ
データの総数を指定します。列データセットを指定するか、スペース区切りの値を入力します。（サンプルサイズは0より大きい必要があります。）

平均の t 検定

検定する平均 検定する仮説上の平均値です。値を入力すると、帰無仮説と対立仮説がそれに応じて調整されます。
帰無仮説 検定する帰無仮説です。

（平均=検定の平均）

対立仮説 対立仮説です。

オプション：

平均 <> 検定平均

両側検定に使用します。標本平均が仮定した平均と異なるかどうかを検定します。

平均 > 検定平均

上側検定に使用します。標本平均が仮定した平均より大きいかどうかを検定します。

平均 < 検定平均

下側検定に使用します。標本平均が仮定した平均より小さいかどうかを検定します。
有意水準 有意水準を指定します。
効果量 効果量 Cohen’s d を計算します。これは実際の平均と検定平均の差の大きさを示します。
信頼区間 平均の信頼区間を計算します。

計算の詳細についてはアルゴリズム（One-Sample T-Test）を参照してください。

%単位での信頼水準 信頼水準 (1 - )% をスペース区切りで指定します。信頼区間が選択されている場合にのみ使用できます。

検出力解析

最小関心差を設定しない場合

指定した検出力に対する差 最小関心差が設定されていない場合、このオプションを使用できます。

指定した検出力レベルに対応する差を出力します。このオプションを選択すると、指定した検出力レベルの設定が、検出力曲線内の検出力レベルに反映されます。

検出力レベル 指定した検出力に対する差オプションをオンにした場合、この編集ボックスに検出力水準をスペース区切りで入力できます。デフォルトの検出力水準は 60%、70%、80%、90% です。

最小関心差を設定する場合

関心のある最小差(MDI) 検定する平均からの最小差を指定します。ここに値を入力すると、検出力解析のグラフに、この差を検出するために必要なサンプルサイズが異なる検出力ごとに表示されます。
指定された検出力のサンプルサイズ 関心のある最小差にチェックを付けた場合に使用できます。

指定した検出力レベルに対応する標本サイズを出力します。このオプションを選択すると、指定した検出力レベルの設定が、検出力曲線内の検出力レベルに反映されます。

検出力レベル 指定した検出力に対する標本サイズオプションをオンにした場合、この編集ボックスに検出力水準をスペース区切りで入力できます。デフォルトの検出力水準は 60%、70%、80%、90% です。
検定データに基づく検出力 関心のある最小差を指定した場合に使用できます。

検定データのサンプルサイズでの検出力を計算します。（帰無仮説が偽であるときに帰無仮説を棄却する確率）

仮説の検出力 関心のある最小差を指定した場合に使用できます。

指定したサンプルサイズでの検出力を計算します。このオプションにチェックを入れると、下のボックスに仮説のサンプルサイズを指定することができ、対応する曲線が検出力曲線に追加されます。

仮説のサンプルサイズ 関心のある最小差を指定し、仮説の検出力をオンにした場合、このオプションを使用できます。

検出力計算のための仮想サンプルサイズを指定します。

Note: 複数のデータ（素データと要約データの両方）を入力した場合、検出力解析レポートは出力されません。

プロット

確率プロット 確率プロットを出力します。
ボックスチャート ボックスチャートをプロットします。

Note:データセットに外れ値が検出されると、ボックスチャートの下に脚注として、そのケースを確認するためのメモが表示されます。外れ値を除外したい場合は、脚注の最後にある三角形のボタンをクリックして外れ値をマークし、再計算できます。

ヒストグラム ヒストグラムをプロットします。
グラフ中に同じ形式のプロットを配列 ヒストグラムの場合レイヤは縦に並びます。ボックスチャートの場合、レイヤは横に並びます。
Note:入力データ形式が要約データの場合、プロットは利用できません。

出力

範囲制御についてはこちらを参照してください：出力結果

結果ログの出力

選択すると結果を結果ログに出力します。

グラフィカル要約レポート サマリーグラフを作成します。内容には P値バー、効果量バー、データの分布グラフが含まれます。また、統計値を示す結果表がグラフに添付されます。

サマリーグラフの脚注として、これらの統計結果の診断が表示されます。

グラフィカル検出力解析レポート 検出力曲線を含むグラフィカルな検出力分析レポートを作成します。 出力テーブルと検出力曲線は、検出力解析タブの設定に従います。
  • 関心のある最小差に値が設定されていない場合、現在のサンプルサイズの検出力曲線のみが出力され、60%、70%、80%、90%（デフォルト値）の検出力における差が表示されます。
  • 関心のある最小差に値が設定されている場合、60%、70%、80%、90%（デフォルト値）と現在のサンプルサイズの検出力曲線が出力され、最小差を検出するために必要なサンプルサイズが一覧表示されます。

検出力曲線グラフの後に検出力解析の診断結果を示す脚注を追加で表示します。検出力の値 80% は一般的に十分と見なされます。

プロットデータ出力 プロットデータの出力用ワークシートを指定します (Originはプロットの作成時に表形式のデータを生成します)。

これは、入力データ形式が素データであるときにのみ有効です。

結果出力 結果を出力するワークシートを指定します。
Note:
  • 入力データ形式が要約データの場合、グラフィカル要約オプションは使用できません。
  • 複数のデータ（素データと要約データの両方）を入力した場合、グラフィカル検出力解析レポートは出力されません。
  • 入力データ形式が素データの場合、マスクされたデータと不正データ（欠損値）表がレポートシートに表示されます。
