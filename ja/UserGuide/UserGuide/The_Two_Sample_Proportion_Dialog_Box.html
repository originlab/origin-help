サポート情報

2群の比率の検定ダイアログボックスを開くには、

  1. ワークシートがアクティブな状態で、統計：仮説検定：2群の比率の検定をクリックします。

比率検定

検定差 検定する仮定上の比率差です（通常は「0」）。
帰無仮説 検定する帰無仮説です。
対立仮説 オプション：
  • 比率 1 - 比率2 <>検定差
比率1 - 比率2 = 検定差という仮説に対して両側検定を実行します。
  • 比率1 - 比率2 > 検定差
比率1 - 比率2 が検定差より大きいという仮説に対して上側片側検定を実行します。
  • 比率1 - 比率2 < 検定差
比率1 - 比率2 が 検定差より小さいという仮説に対して下側片側検定を実行します。
有意水準 検定の有意水準。
信頼区間 比率差の信頼区間を計算します。
%単位での信頼水準 信頼区間を計算する信頼水準を指定します。このオプションは信頼区間が選択されている場合にのみ利用可能です。
検定方法 検定方法の詳細については、アルゴリズムのページを参照してください。
  • 正規近似
正規近似により、結果の p 値および信頼区間を計算します。
  • 検定にプールしたpを使用
検定差が 0 の場合に、検定で pのプール推定値を使用するかどうかを指定します。
  • Fisher の正確確率検定
p二項検定に基づく Fisher の正確確率検定により、p 値および信頼区間を計算します。

検出力解析

最小関心差を設定しない場合

指定した検出力に対する差 最小関心差が設定されていない場合、このオプションを使用できます。

指定した検出力レベルに対応する差を出力します。このオプションを選択すると、指定した検出力レベルの設定が、検出力曲線内の検出力レベルに反映されます。

検出力レベル 指定した検出力に対する差オプションをオンにした場合、この編集ボックスに検出力水準をスペース区切りで入力できます。デフォルトの検出力水準は 60%、70%、80%、90% です。

最小関心差を設定する場合

関心のある最小差(MDI) 関心のある最小の差を指定します。このボックスに値を入力すると、検出力分析グラフには、異なる検出力でこの差を検出するために必要な最小標本サイズが表示されます。
Note:

2標本比率検定では、最小関心差（MDI）の設定に制限があります。これはPlotDataワークシートに出力される差の境界値に関連します。

  • 比率1 - 比率2 <> 検定差 の場合、MDIは0より大きく、差の上限と差の下限の絶対値のうち小さい方より小さい値である必要があります。
  • 比率1 - 比率2 > 検定差 の場合、MDIは0より大きく、差の上限より小さい値である必要があります。
  • 比率1 - 比率2 < 検定差 の場合、MDIは0より大きく、差の下限の絶対値より小さい値である必要があります。
指定された検出力のサンプルサイズ 関心のある最小差にチェックを付けた場合に使用できます。

指定した検出力レベルに対応する標本サイズを出力します。このオプションを選択すると、指定した検出力レベルの設定が、検出力曲線内の検出力レベルに反映されます。選択しない場合は、デフォルトの検出力レベルが使用されます。

検出力レベル 指定した検出力に対する標本サイズオプションをオンにした場合、この編集ボックスに検出力水準をスペース区切りで入力できます。デフォルトの検出力水準は 60%、70%、80%、90% です。
検定データに基づく検出力 関心のある最小差を指定した場合に使用できます。

検定データのサンプルサイズでの検出力を計算します。（帰無仮説が偽であるときに帰無仮説を棄却する確率）

仮説の検出力 関心のある最小差を指定した場合に使用できます。

サンプルサイズを変化させた場合の検出力を計算します。このオプションにチェックを付けると、対応する曲線が検出力曲線に追加されます。

仮説のサンプルサイズ 関心のある最小差を指定し、仮説の検出力をオンにした場合、このオプションを使用できます。

検出力計算のための仮想サンプルサイズを指定します。

出力

結果ログの出力 選択すると結果を結果ログに出力します。

グラフィカル検出力解析レポート 検出力解析レポートをグラフィカルに表示するかどうかを指定します。検出力曲線は、比率の差の変化に応じて検定の統計的検出力がどのように変化するかを示します。検出力とは、真の差が0と異なる場合に帰無仮説を棄却する確率です。
