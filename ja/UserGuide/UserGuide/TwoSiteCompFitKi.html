関数





説明

2種類の受容体に対するリガンドの競合を記述する2部位競合結合関数。

サンプル曲線

パラメータ

パラメータ数:  8

パラメータ名: A1, A2, logKi_1, logKi_2, fraction, H1, H2_1, H2_2

意味： A1 = 上側漸近線、A2 = 下側漸近線、logKi_1 = 高親和性部位のKiの常用対数（log10 Ki）、logKi_2 = 低親和性部位のKiの常用対数（log10 Ki）、fraction = 高親和性部位の割合、H1 = 標識リガンド濃度、H2_1 = 高親和性部位に対する標識リガンドの平衡解離定数（Kd）、H2_2 = 低親和性部位に対する標識リガンドの平衡解離定数（Kd）

下側境界: なし

上側境界: なし

派生パラメータ

Ki_1=10^(logKi_1)

Ki_2=10^(logKi_2)

EC50_1=10^(logKi_1)*(1+H1/H2_1)

EC50_2=10^(logKi_2)*(1+H1/H2_2)

スクリプトでのアクセス法

nlf_TwoSiteCompFitKi(x,A1,A2,logKi_1,logKi_2,fraction,H1,H2_1,H2_2)
